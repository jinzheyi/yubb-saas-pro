# 消息列表群聊显示 - 实现说明

## 概述
在消息列表页面（message.uvue）中添加了5条群聊模拟消息，展示不同的群聊场景和状态。

## 实现内容

### 1. 添加的群聊消息

| 序号 | 群聊名称 | 最后消息 | 未读数 | 状态 | 成员数 | 特点 |
|------|---------|---------|--------|------|--------|------|
| 1 | 产品研发团队 | 张敏: 今天下午3点开会... | 15 | 置顶 | 12人 | 工作群，有未读消息 |
| 2 | 张敏、李强、王静等4人 | 李强: [图片] | 3 | 置顶 | 4人 | 小群聊，图片消息 |
| 3 | 技术交流群 | 刘洋: 这个问题我来解答... | 99+ | 普通 | 50人 | 大群，消息很多 |
| 4 | 周末聚会 | 王静: 大家周末有空吗？ | 0 | 免打扰 | 8人 | 免打扰群 |
| 5 | 项目管理组 | 赵敏: @我 请查看... | 5 | 普通 | 15人 | 有@消息 |

### 2. 群聊消息特点

#### 视觉标识
- ✅ 群聊图标：使用 `\ue616` 图标
- ✅ 成员数量：显示在群名后面，格式：`(N)`
- ✅ 不同颜色：每个群聊有独特的背景色

#### 消息状态
- ✅ 未读数量：支持显示未读消息数（包括99+）
- ✅ 免打扰：支持免打扰模式（只显示红点）
- ✅ 置顶：支持置顶显示
- ✅ @消息：支持@提醒标识

#### 时间显示
- ✅ 5分钟前：产品研发团队
- ✅ 15分钟前：张敏、李强、王静等4人
- ✅ 30分钟前：技术交流群
- ✅ 2小时前：周末聚会
- ✅ 4小时前：项目管理组

### 3. 功能实现

#### 点击跳转
```typescript
function handleMessageClick(item: any) {
  if (item.isGroup) {
    // 跳转到群聊页面
    uni.navigateTo({
      url: `/pages/message/chat?type=group&groupId=${item.id}&name=${encodeURIComponent(item.title)}&memberCount=${item.memberCount || 0}`
    })
  } else {
    // 跳转到单聊页面
    uni.navigateTo({
      url: '/pages/message/chat?name=' + (item.titleKey ? t(item.titleKey) : item.title)
    })
  }
}
```

#### 成员数量显示
```vue
<view class="message-name-wrap">
  <text class="message-name">{{ item.title }}</text>
  <text v-if="item.isGroup && item.memberCount" class="member-count">
    ({{ item.memberCount }})
  </text>
</view>
```

### 4. 数据结构

```typescript
{
  id: 1,
  categoryId: 'group',           // 分类ID
  title: '产品研发团队',          // 群聊名称
  desc: '张敏: 今天下午3点开会',  // 最后消息
  lastMessageTime: timestamp,    // 最后消息时间
  avatarBg: '#10b981',          // 头像背景色
  avatarText: '产品',           // 头像文字（备用）
  avatarIcon: '\ue616',         // 群聊图标
  unreadCount: 15,              // 未读数量
  noDisturb: false,             // 是否免打扰
  isPinned: true,               // 是否置顶
  pinnedTime: timestamp,        // 置顶时间
  isGroup: true,                // 是否是群聊
  memberCount: 12,              // 成员数量
  hasAt: false                  // 是否有@消息（可选）
}
```

## 与单聊的区别

| 特性 | 单聊 | 群聊 |
|------|------|------|
| 头像 | 用户头像文字 | 群聊图标 |
| 名称 | 用户名 | 群聊名称 + 成员数 |
| 跳转参数 | name | type=group&groupId&name&memberCount |
| 消息格式 | 直接显示内容 | 发送者: 内容 |
| 标识 | isGroup: false | isGroup: true |
