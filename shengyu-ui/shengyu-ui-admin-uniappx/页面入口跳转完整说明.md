## 二、群聊设置页入口

### 1. 从群聊页面进入

**入口位置：** 聊天页面 (`pages/message/chat.uvue`) 右上角"..."按钮

**跳转方式：**
```typescript
function handleToSettings() {
  if (chatType.value === 'group') {
    // 群聊跳转到群聊设置页
    uni.navigateTo({
      url: `/pages/message/group-settings?groupId=${groupId.value}&name=${encodeURIComponent(name.value)}`
    })
  } else {
    // 单聊跳转到聊天设置页
    uni.navigateTo({
      url: '/pages/message/chat-settings'
    })
  }
}
```

**触发条件：** 在群聊页面点击右上角"..."图标

**用户路径：**
```
消息列表 → 点击群聊 → 聊天页面 → 点击"..." → 群聊设置页
```

**传递参数：**
- `groupId`: 群聊ID
- `name`: 群聊名称

## 注意事项

### 1. 搜索框禁用输入

为了确保点击搜索框跳转到搜索页面，搜索框的 input 组件添加了 `disabled` 属性：

```vue
<input class="search-input" disabled />
```

这样用户点击搜索框时会触发父容器的点击事件，跳转到搜索页面。

### 2. 群聊类型判断

聊天页面根据 `type` 参数判断是单聊还是群聊：

```typescript
if (chatType.value === 'group') {
  // 群聊逻辑
} else {
  // 单聊逻辑
}
```

### 3. 参数传递

所有跳转都使用 URL 参数传递数据：

```typescript
// 传递参数
url: `/pages/message/group-settings?groupId=${groupId}&name=${encodeURIComponent(name)}`

// 接收参数
onLoad((options : any) => {
  if (options['groupId']) {
    groupId.value = parseInt(options['groupId'])
  }
  if (options['name']) {
    name.value = decodeURIComponent(options['name'])
  }
})
```

### 4. 中文编码

传递中文参数时需要使用 `encodeURIComponent` 编码，接收时使用 `decodeURIComponent` 解码。
