# 验证码调试指南

## 问题：验证码图片未显示

### 可能的原因

1. **后端接口地址不正确**
2. **网络请求失败**
3. **响应数据格式不匹配**
4. **图片 Base64 数据为空**
5. **跨域问题**

---

## 调试步骤

### 1. 检查后端地址配置

编辑 `config/app.config.uts`，确认后端地址正确：

```typescript
// 确保地址正确，不要有多余的斜杠
export const BASE_URL = 'http://localhost:48080'

// 或者使用你的实际后端地址
// export const BASE_URL = 'http://10.108.11.46:8088'
```

### 2. 查看控制台日志

打开 HBuilderX 的控制台，查看以下日志：

```
获取验证码请求参数: { captchaType, clientUid, ts }
获取验证码响应: { repCode, repData, ... }
验证码图片已加载: { hasBackImg, hasBlockImg, token }
```

**正常情况**:
```json
{
  "repCode": "0000",
  "repData": {
    "originalImageBase64": "iVBORw0KGgo...",
    "jigsawImageBase64": "iVBORw0KGgo...",
    "token": "xxx",
    "secretKey": "xxx"
  }
}
```

**异常情况**:
- `repCode` 不是 "0000"
- `repData` 为空
- `originalImageBase64` 或 `jigsawImageBase64` 为空

### 3. 测试后端接口

使用 Postman 或 curl 测试后端接口：

```bash
# 测试获取验证码接口
curl -X POST http://localhost:48080/admin-api/system/captcha/get \
  -H "Content-Type: application/json" \
  -d '{
    "captchaType": "blockPuzzle",
    "clientUid": "test-123",
    "ts": 1234567890
  }'
```

**预期响应**:
```json
{
  "repCode": "0000",
  "repMsg": "success",
  "repData": {
    "originalImageBase64": "...",
    "jigsawImageBase64": "...",
    "token": "...",
    "secretKey": "..."
  }
}
```

### 4. 检查网络请求

在 HBuilderX 控制台的 Network 标签中查看请求：

- **请求 URL**: `http://localhost:48080/admin-api/system/captcha/get`
- **请求方法**: POST
- **请求头**: Content-Type: application/json
- **请求体**: `{ captchaType, clientUid, ts }`
- **响应状态**: 200
- **响应数据**: 包含 repCode 和 repData

### 5. 检查图片显示

在组件中添加调试代码：

```vue
<template>
  <view class="captcha-image-container">
    <!-- 显示调试信息 -->
    <text v-if="!backImgBase">背景图未加载</text>
    <text v-if="!blockImgBase">滑块图未加载</text>
    
    <!-- 背景图 -->
    <image 
      class="captcha-bg-image" 
      :src="backImgBase ? ('data:image/png;base64,' + backImgBase) : ''"
      mode="aspectFill"
      @error="handleImageError"
      @load="handleImageLoad"
    ></image>
  </view>
</template>

<script>
function handleImageError(e: any) {
  console.error('图片加载失败:', e)
}

function handleImageLoad(e: any) {
  console.log('图片加载成功:', e)
}
</script>
```

## 常见问题解决

### 问题 1: 后端接口返回 404

**原因**: 后端地址不正确或接口路径错误

**解决**:
```typescript
// 检查 config/app.config.uts
export const BASE_URL = 'http://localhost:48080'

// 完整的接口地址应该是：
// http://localhost:48080/admin-api/system/captcha/get
```

### 问题 2: 后端接口返回 401

**原因**: 验证码接口不应该需要 Token

**解决**: 检查后端 `CaptchaController.java`，确保接口有 `@PermitAll` 注解：

```java
@PostMapping({"/get"})
@Operation(summary = "获得验证码")
@PermitAll  // 允许匿名访问
@TenantIgnore
@OperateLog(enable = false)
public ResponseModel get(@RequestBody CaptchaVO data, HttpServletRequest request) {
    // ...
}
```

### 问题 3: 图片 Base64 数据为空

**原因**: 后端验证码服务未正确配置

**解决**: 检查后端配置文件，确保验证码资源文件存在：

```yaml
# application.yml
aj:
  captcha:
    # 验证码类型
    type: default
    # 滑动验证，底图路径
    jigsaw: classpath:images/jigsaw
    # 滑动验证，滑块路径
    pic-click: classpath:images/pic-click
```

### 问题 4: 跨域问题

**原因**: 前端和后端不在同一域名

**解决**: 后端添加 CORS 配置：

```java
@Configuration
public class CorsConfig {
    @Bean
    public CorsFilter corsFilter() {
        CorsConfiguration config = new CorsConfiguration();
        config.addAllowedOriginPattern("*");
        config.addAllowedMethod("*");
        config.addAllowedHeader("*");
        config.setAllowCredentials(true);
        
        UrlBasedCorsConfigurationSource source = new UrlBasedCorsConfigurationSource();
        source.registerCorsConfiguration("/**", config);
        
        return new CorsFilter(source);
    }
}
```

### 问题 5: 响应数据格式不匹配

**原因**: 响应拦截器错误处理了验证码接口

**解决**: 已在 `api/login.uts` 中修复，验证码接口不经过响应拦截器：

```typescript
export function getCaptcha(data: UTSJSONObject): Promise<any> {
  return new Promise((resolve, reject) => {
    uni.request({
      // ...
      success: (res) => {
        // 直接返回原始数据，不经过响应拦截器
        if (res.statusCode == 200) {
          resolve(res.data)
        }
      }
    })
  })
}
```

## 临时解决方案

如果仍然无法显示图片，可以使用以下临时方案：

### 方案 1: 使用测试图片

```vue
<script>
// 在 loadCaptcha 函数中添加测试数据
async function loadCaptcha() {
  // 临时使用测试图片
  backImgBase.value = 'iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mNk+M9QDwADhgGAWjR9awAAAABJRU5ErkJggg=='
  blockImgBase.value = 'iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mNk+M9QDwADhgGAWjR9awAAAABJRU5ErkJggg=='
  token.value = 'test-token'
  secretKey.value = 'test-key'
  
  console.log('使用测试图片')
}
</script>
```

### 方案 2: 直接请求后端

```typescript
// 绕过 API 封装，直接请求
async function loadCaptcha() {
  try {
    const res = await uni.request({
      url: 'http://localhost:48080/admin-api/system/captcha/get',
      method: 'POST',
      data: {
        captchaType: 'blockPuzzle',
        clientUid: 'test-123',
        ts: Date.now()
      },
      header: {
        'Content-Type': 'application/json'
      }
    })
    
    console.log('直接请求响应:', res)
    
    if (res.data.repCode == '0000') {
      backImgBase.value = res.data.repData.originalImageBase64
      blockImgBase.value = res.data.repData.jigsawImageBase64
      token.value = res.data.repData.token
      secretKey.value = res.data.repData.secretKey
    }
  } catch (e) {
    console.error('直接请求失败:', e)
  }
}
```
