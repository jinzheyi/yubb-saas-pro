# 验证码实现说明

## 概述
App 端验证码逻辑严格参考 PC 端 Vue3 实现，确保两端行为完全一致。

## PC 端验证码逻辑

### 配置方式
```javascript
// .env 文件
VITE_APP_CAPTCHA_ENABLE=true

// LoginForm.vue
const loginData = reactive({
  captchaEnable: import.meta.env.VITE_APP_CAPTCHA_ENABLE,
  // ...
})
```

### 判断逻辑
```javascript
// PC 端 getCode 方法
const getCode = async () => {
  // 情况一，未开启：则直接登录
  if (loginData.captchaEnable === 'false') {
    await handleLogin({})
  } else {
    // 情况二，已开启：则展示验证码；只有完成验证码的情况，才进行登录
    // 弹出验证码
    verify.value.show()
  }
}
```

### 关键点
1. **字符串比较**：`captchaEnable === 'false'`（注意是字符串 'false'，不是布尔值）
2. **仅账号登录使用**：手机号登录不使用滑块验证码
3. **验证码组件**：使用 `<Verify>` 组件（第三方验证码库）

## App 端验证码逻辑

### 配置方式
```typescript
// config/app.config.uts
export const CAPTCHA_ENABLE = 'true' // 'true' 启用，'false' 禁用

// login.uvue
import { CAPTCHA_ENABLE } from '../../config/app.config.uts'

const captchaEnable = ref<string>(CAPTCHA_ENABLE)
```

### 判断逻辑
```typescript
// App 端 handleLogin 方法
async function handleLogin() {
  if (loginType.value === 'account') {
    // 验证表单...
    
    // 严格参考 PC 端验证码逻辑
    // 情况一，未开启：则直接登录
    if (captchaEnable.value === 'false') {
      await doLogin('')
    } else {
      // 情况二，已开启：则展示验证码；只有完成验证码的情况，才进行登录
      if (captchaRef.value) {
        captchaRef.value.show()
      }
    }
  } else {
    // 手机号登录不需要验证码，直接登录
    await doLogin('')
  }
}
```

### 关键点
1. **字符串比较**：`captchaEnable.value === 'false'`（与 PC 端完全一致）
2. **仅账号登录使用**：手机号登录不使用滑块验证码（与 PC 端一致）
3. **验证码组件**：使用 `<slider-captcha>` 组件（自定义实现）

## 验证码组件对比

### PC 端 - Verify 组件
```vue
<Verify
  ref="verify"
  :captchaType="captchaType"
  :imgSize="{ width: '400px', height: '200px' }"
  mode="pop"
  @success="handleLogin"
/>
```

**特点**：
- 第三方验证码库（vue3-puzzle-vcode）
- 支持滑块拼图、点击文字等多种类型
- 弹窗模式
- 验证成功回调

### App 端 - slider-captcha 组件
```vue
<slider-captcha 
  ref="captchaRef" 
  captchaType="blockPuzzle"
  @success="handleCaptchaSuccess"
  @fail="handleCaptchaFail"
/>
```

**特点**：
- 自定义实现
- 支持滑块拼图
- 弹窗模式
- 验证成功/失败回调

## 代码实现细节

### 1. 配置文件
```typescript
// config/app.config.uts
/**
 * 验证码的开关
 * PC 端：VITE_APP_CAPTCHA_ENABLE=true
 * 
 * 使用说明：
 * - 'true'：启用验证码（账号登录时显示滑块验证码）
 * - 'false'：禁用验证码（直接登录，无需验证码）
 * 
 * 注意：手机号登录不使用滑块验证码，仅使用短信验证码
 */
export const CAPTCHA_ENABLE = 'true'
```

### 2. 登录页面
```typescript
// pages/login/login.uvue
import { CAPTCHA_ENABLE } from '../../config/app.config.uts'

// 验证码配置（严格参考 PC 端）
const captchaEnable = ref<string>(CAPTCHA_ENABLE)

// 登录按钮点击（严格参考 PC 端 getCode 方法）
async function handleLogin() {
  if (loginType.value === 'account') {
    // 验证表单...
    
    // 严格参考 PC 端验证码逻辑
    if (captchaEnable.value === 'false') {
      await doLogin('')
    } else {
      if (captchaRef.value) {
        captchaRef.value.show()
      }
    }
  } else {
    // 手机号登录不需要验证码
    await doLogin('')
  }
}
```

### 3. 验证码组件
```typescript
// components/captcha/slider-captcha.uvue
// 验证成功
function handleCaptchaSuccess(data: any) {
  captchaVerification.value = data.captchaVerification
  doLogin(data.captchaVerification)
}

// 验证失败
function handleCaptchaFail() {
  uni.showToast({
    title: '验证失败，请重试',
    icon: 'none'
  })
}
```

## 常见问题

### Q1: 为什么使用字符串 'false' 而不是布尔值 false？
A: 严格参考 PC 端实现。PC 端从环境变量读取的值是字符串类型，所以判断逻辑使用 `=== 'false'`。App 端为了保持一致性，也使用字符串类型。

### Q2: 如何在开发时禁用验证码？
A: 修改 `config/app.config.uts` 文件：
```typescript
export const CAPTCHA_ENABLE = 'false'
```

### Q3: 手机号登录为什么不使用滑块验证码？
A: 
1. 手机号登录已经使用了短信验证码，安全性足够
2. 避免用户操作过于繁琐
3. 与 PC 端逻辑保持一致

### Q4: 验证码组件加载失败怎么办？
A:
1. 检查网络连接
2. 确认后端验证码接口正常
3. 查看控制台错误信息
4. 临时禁用验证码进行测试
