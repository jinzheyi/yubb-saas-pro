# 国际化参数替换功能修复说明

## 问题描述

在发起群聊页面中，使用国际化显示选中人数时，页面一直显示 `{count}` 占位符，而不是实际的数字。

```vue
<!-- 问题代码 -->
<text>{{ t('initiateGroup.selectedCount', { count: selectedCount.toString() }) }}</text>
<!-- 显示结果：已选择:{count} 人 -->
```

## 问题原因

原有的 `t()` 翻译函数只是简单地返回翻译文本，没有处理参数替换逻辑。

```typescript
// 原有实现（不支持参数替换）
export function t(key: string, defaultValue?: string): string {
  const messages = getCurrentMessages()
  // ... 查找翻译文本
  return value || defaultValue || key
}
```

## 解决方案

### 1. 增强 `t()` 函数支持参数替换

**文件**: `store/locale.uts`

```typescript
/**
 * 翻译函数
 * @param key 翻译键（支持点号分隔的路径，如 'common.login'）
 * @param params 参数对象或默认值（可选）
 * @returns 翻译后的文本
 */
export function t(key: string, params?: any): string {
  const messages = getCurrentMessages()
  
  // 分割键路径
  const keys = key.split('.')
  let value: any = messages
  
  // 逐级查找
  for (let i = 0; i < keys.length; i++) {
    if (value && typeof value === 'object') {
      value = value[keys[i]]
    } else {
      value = null
      break
    }
  }
  
  // 如果找到翻译文本
  if (value && typeof value === 'string') {
    // 如果 params 是对象，进行参数替换
    if (params && typeof params === 'object') {
      let result = value
      // 替换所有 {key} 格式的占位符
      for (const paramKey in params) {
        const regex = new RegExp('\\{' + paramKey + '\\}', 'g')
        result = result.replace(regex, params[paramKey].toString())
      }
      return result
    }
    return value
  }
  
  // 如果 params 是字符串，作为默认值返回
  if (params && typeof params === 'string') {
    return params
  }
  
  return key
}
```

### 2. 更新 useI18n Hook

**文件**: `hooks/useI18n.uts`

```typescript
/**
 * 翻译函数（响应式）
 * @param key 翻译键
 * @param params 参数对象或默认值
 * @returns 翻译后的文本
 */
const t = (key: string, params?: any): string => {
  // 依赖 locale.value 确保响应式更新
  const currentLocale = locale.value
  return translate(key, params)
}
```

## 使用方法

### 基础用法（无参数）

```typescript
// 简单翻译
t('common.login')  // 返回：登录

// 带默认值
t('unknown.key', '默认文本')  // 返回：默认文本
```

### 参数替换用法

```typescript
// 单个参数
t('initiateGroup.selectedCount', { count: '5' })
// 返回：已选择 5 人

// 多个参数
t('message.template', { name: '张三', count: '10' })
// 配置：'你好 {name}，你有 {count} 条新消息'
// 返回：你好 张三，你有 10 条新消息
```

### 在组件中使用

```vue
<template>
  <view>
    <!-- 无参数 -->
    <text>{{ t('common.login') }}</text>
    
    <!-- 带参数 -->
    <text>{{ t('initiateGroup.selectedCount', { count: selectedCount.toString() }) }}</text>
    
    <!-- 多个参数 -->
    <text>{{ t('message.greeting', { name: userName, time: currentTime }) }}</text>
  </view>
</template>

<script setup lang="uts">
import { useI18n } from '../../hooks/useI18n.uts'

const { t } = useI18n()

const selectedCount = ref(5)
const userName = ref('张三')
const currentTime = ref('上午')
</script>
```

## 参数占位符格式

- 使用 `{paramName}` 格式定义占位符
- 参数名区分大小写
- 支持多个参数
- 参数会自动转换为字符串

### 示例

```typescript
// 语言包配置
{
  welcome: '欢迎 {name}',
  stats: '共 {total} 条，已完成 {done} 条',
  percent: '进度：{value}%'
}

// 使用
t('welcome', { name: '张三' })
// 返回：欢迎 张三

t('stats', { total: '100', done: '80' })
// 返回：共 100 条，已完成 80 条

t('percent', { value: '75' })
// 返回：进度：75%
```

## 兼容性说明

### 向后兼容

修改后的 `t()` 函数完全向后兼容：

```typescript
// 旧用法（仍然有效）
t('common.login')
t('common.login', '默认值')

// 新用法（参数替换）
t('message.count', { count: '5' })
```

### 参数类型

- **对象参数**: 进行参数替换
- **字符串参数**: 作为默认值
- **无参数**: 返回翻译文本或键名

## 注意事项

1. **占位符格式**: 必须使用 `{paramName}` 格式，不支持其他格式
2. **参数对象**: 传入的参数必须是对象，不能是数组或其他类型
3. **参数值**: 所有参数值会自动调用 `.toString()` 转换为字符串
4. **正则转义**: 参数名中不要包含正则特殊字符（如 `$`, `^`, `*` 等）
5. **性能考虑**: 参数替换使用正则表达式，大量使用时注意性能
