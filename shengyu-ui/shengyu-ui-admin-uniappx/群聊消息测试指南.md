# 群聊消息测试指南

## 快速测试步骤

### 1. 查看消息列表中的群聊（3秒）

```
打开应用 → 进入"消息"页面 → 查看前5条消息
```

**预期结果：**
- ✅ 看到5条群聊消息（带群聊图标）
- ✅ 前2条置顶显示（浅灰色背景）
- ✅ 每条群聊显示成员数量，如：(12)、(4)、(50)等
- ✅ 未读数量正确显示（15、3、99+等）

### 2. 点击群聊消息（5秒）

```
点击"产品研发团队" → 查看群聊页面
```

**预期结果：**
- ✅ 跳转到群聊页面
- ✅ 头部显示"产品研发团队"
- ✅ 头部显示"12人"
- ✅ 显示5条群聊消息
- ✅ 可以发送消息

### 3. 测试不同类型的群聊（10秒）

#### 测试1：小群聊
```
返回消息列表 → 点击"张敏、李强、王静等4人"
```
- ✅ 显示"4人"
- ✅ 群名显示完整

#### 测试2：大群
```
返回消息列表 → 点击"技术交流群"
```
- ✅ 显示"50人"
- ✅ 未读数显示"99+"

#### 测试3：免打扰群
```
返回消息列表 → 查看"周末聚会"
```
- ✅ 只显示红点，不显示数字
- ✅ 有免打扰图标

### 4. 创建新群聊（15秒）

```
消息页面 → 点击"+" → 选择3个联系人 → 确定
```

**预期结果：**
- ✅ 创建成功
- ✅ 跳转到新群聊页面
- ✅ 群名自动生成（如：张敏、李强、王静等4人）
- ✅ 显示成员数量
