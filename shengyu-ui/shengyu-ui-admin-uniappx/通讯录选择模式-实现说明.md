# 通讯录选择模式实现说明

## 概述

为发起群聊功能实现了通讯录页面的选择模式，支持从我的群组、我的关注、组织结构、我的部门四个入口选择成员。组织结构页面支持层级选择（选中组织/部门自动选中所有成员）。

### 3. 组织结构 - 选择模式（层级选择）

**文件**: `pages/contacts/organization.uvue`

**功能**:

- ✅ 显示复选框
- ✅ 底部显示已选择人数

**触发方式**:
```typescript
uni.navigateTo({
  url: '/pages/contacts/organization?mode=select'
})
```

**层级选择逻辑**:

**向下联动**（选中父级自动选中子级）:
```typescript
// 切换组织选中状态
function toggleOrgSelect(org : any) {
  org.selected = !org.selected
  // 同步选中状态到所有部门和成员
  for (let i = 0; i < org.departments.length; i++) {
    const dept = org.departments[i]
    dept.selected = org.selected
    for (let j = 0; j < dept.members.length; j++) {
      dept.members[j].selected = org.selected
    }
  }
}

// 切换部门选中状态
function toggleDeptSelect(org : any, dept : any) {
  dept.selected = !dept.selected
  // 同步选中状态到所有成员
  for (let i = 0; i < dept.members.length; i++) {
    dept.members[i].selected = dept.selected
  }
  // 检查是否需要更新组织的选中状态
  updateOrgSelectState(org)
}
```

**向上联动**（所有子级选中时父级自动选中）:
```typescript
// 更新部门的选中状态
function updateDeptSelectState(dept : any) {
  if (dept.members.length === 0) {
    dept.selected = false
    return
  }
  dept.selected = dept.members.every(m => m.selected)
}

// 更新组织的选中状态
function updateOrgSelectState(org : any) {
  if (org.departments.length === 0) {
    org.selected = false
    return
  }
  org.selected = org.departments.every(d => d.selected)
}

// 切换成员选中状态
function toggleMemberSelect(member : any) {
  member.selected = !member.selected
  
  // 查找成员所属的部门和组织，更新它们的选中状态
  for (let i = 0; i < organizations.value.length; i++) {
    const org = organizations.value[i]
    for (let j = 0; j < org.departments.length; j++) {
      const dept = org.departments[j]
      if (dept.members.some(m => m.id === member.id)) {
        updateDeptSelectState(dept)
        updateOrgSelectState(org)
        return
      }
    }
  }
}
```

**数据收集**:
```typescript
function handleConfirm() {
  // 收集所有选中的成员
  const selectedMembers : any[] = []
  for (let i = 0; i < organizations.value.length; i++) {
    const org = organizations.value[i]
    for (let j = 0; j < org.departments.length; j++) {
      const dept = org.departments[j]
      for (let k = 0; k < dept.members.length; k++) {
        if (dept.members[k].selected) {
          selectedMembers.push(dept.members[k])
        }
      }
    }
  }
  
  uni.showToast({
    title: `已选择 ${selectedMembers.length} 人`,
    icon: 'success'
  })
  setTimeout(() => {
    uni.navigateBack()
  }, 1000)
}
```

### 2. 选中数量计算

使用 `computed` 实时计算选中数量：

```typescript
const selectedCount = computed(() : number => {
  let count = 0
  for (let i = 0; i < list.value.length; i++) {
    if (list.value[i].selected) {
      count++
    }
  }
  return count
})
```

对于层级结构（组织结构），需要遍历所有层级：

```typescript
const selectedCount = computed(() : number => {
  let count = 0
  for (let i = 0; i < organizations.value.length; i++) {
    const org = organizations.value[i]
    for (let j = 0; j < org.departments.length; j++) {
      const dept = org.departments[j]
      for (let k = 0; k < dept.members.length; k++) {
        if (dept.members[k].selected) {
          count++
        }
      }
    }
  }
  return count
})
```

## 交互流程

### 1. 进入选择模式

```
发起群聊页面 (initiate-group.uvue)
  ↓ 点击分类（我的群组/我的关注/组织结构/我的部门）
  ↓ 传递 mode=select 参数
目标页面 (xxx.uvue?mode=select)
  ↓ onLoad 检测参数
  ↓ 设置 isSelectMode = true
显示选择模式 UI
```

### 2. 选择操作

```
用户点击列表项
  ↓ 判断 isSelectMode
  ↓ 是：切换选中状态
  ↓ 否：跳转到详情页面
更新 UI（复选框状态）
  ↓
更新选中数量
```

### 3. 层级选择（组织结构）

```
用户点击组织
  ↓ toggleOrgSelect(org)
  ↓ 设置 org.selected = !org.selected
  ↓ 遍历所有部门
  ↓   设置 dept.selected = org.selected
  ↓   遍历所有成员
  ↓     设置 member.selected = org.selected
更新 UI

用户点击成员
  ↓ toggleMemberSelect(member)
  ↓ 设置 member.selected = !member.selected
  ↓ 查找所属部门
  ↓   updateDeptSelectState(dept)
  ↓   检查所有成员是否都选中
  ↓   设置 dept.selected = allSelected
  ↓ 查找所属组织
  ↓   updateOrgSelectState(org)
  ↓   检查所有部门是否都选中
  ↓   设置 org.selected = allSelected
更新 UI
```

### 4. 确认返回

```
用户点击确定按钮
  ↓ handleConfirm()
  ↓ 收集所有选中的项
  ↓ 显示提示信息
  ↓ 延迟 1 秒
  ↓ uni.navigateBack()
返回发起群聊页面
```

function toggleSelect(item : any) {

    uni.showToast({
