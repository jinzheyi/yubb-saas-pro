# 快速启动指南

## 1. 环境准备

### 必需工具
- **HBuilderX**: [下载地址](https://www.dcloud.io/hbuilderx.html)
- **Node.js**: 建议 v16+ (可选，用于某些插件)

### 推荐插件
- uni-app 编译器
- uts 语法支持
- 内置浏览器

## 2. 项目配置

### 2.1 修改后端地址

编辑 `utils/request.uts`，第 6 行：

```typescript
const BASE_URL = 'http://localhost:48080' // 修改为你的后端地址
```

### 2.2 修改租户名称（可选）

编辑 `pages/login/login.uvue`，第 48 行：

```typescript
const tenantName = ref<string>('圣钰科技') // 修改为你的租户名称
```

## 3. 运行项目

### 3.1 使用 HBuilderX

1. 打开 HBuilderX
2. 文件 -> 打开目录 -> 选择 `shengyu-ui-admin-uniappx` 目录
3. 点击工具栏的"运行"按钮
4. 选择运行方式：
   - **运行到浏览器**: Chrome/Firefox/Edge
   - **运行到手机**: 真机调试
   - **运行到模拟器**: Android/iOS 模拟器

### 3.2 浏览器运行（推荐）

1. 点击 HBuilderX 菜单：运行 -> 运行到浏览器 -> Chrome
2. 浏览器会自动打开项目
3. 使用浏览器的开发者工具切换到移动设备模式（F12 -> 设备工具栏）

### 3.3 真机调试

1. 手机开启开发者模式和 USB 调试
2. 用 USB 连接手机到电脑
3. HBuilderX 会自动识别设备
4. 点击运行 -> 运行到手机 -> 选择你的设备

## 4. 测试登录

### 4.1 账号密码登录

1. 打开应用，进入登录页

## 6. 常见问题

### Q1: 无法连接后端？
**A**: 检查以下几点：
- 后端服务是否已启动
- `utils/request.uts` 中的 BASE_URL 是否正确
- 网络是否连通（可以 ping 后端地址）
- 防火墙是否阻止了连接

### Q2: 登录后立即跳回登录页？
**A**: 可能的原因：
- Token 获取失败，检查后端返回的数据格式
- 租户ID 获取失败，检查租户名称是否正确
- 查看浏览器控制台的错误信息

### Q3: TabBar 图标显示不正常？
**A**: 
- 当前使用的是临时图标（logo.png）
- 建议准备专业的 TabBar 图标
- 参考 `static/tabbar/README.md`

### Q4: 验证码收不到？
**A**: 检查：
- 手机号是否正确
- 后端短信服务是否配置
- 查看后端日志

### Q5: HBuilderX 无法识别 UTS 语法？
**A**: 
- 确保 HBuilderX 版本是最新的
- 安装 uni-app 和 uts 相关插件
- 重启 HBuilderX

## 7. 开发建议

### 7.1 调试技巧
- 使用 `console.log()` 输出调试信息
- 使用浏览器开发者工具查看网络请求
- 使用 HBuilderX 的调试功能

### 7.2 代码规范
- 遵循 UTS 语法规范
- 使用 TypeScript 类型注解
- 保持代码简洁清晰

### 7.3 性能优化
- 避免频繁的网络请求
- 使用本地缓存
- 图片资源压缩

## 8. 打包发布

### 8.1 App 打包

1. 点击 HBuilderX 菜单：发行 -> 原生 App-云打包
2. 选择打包平台（Android/iOS）
3. 配置应用信息
4. 提交打包
5. 等待打包完成，下载安装包

### 8.2 小程序打包

1. 点击 HBuilderX 菜单：发行 -> 小程序-微信
2. 配置小程序 AppID
3. 上传代码
4. 在微信开发者工具中预览和提交审核
