# UniApp 移动端快速开始

## 登录功能说明

### 账号密码登录
1. 输入租户名称（默认：圣钰科技）
2. 输入账号
3. 输入密码
4. 可选：勾选"记住我"
5. 点击登录
6. 完成滑块验证码
7. 登录成功

### 手机号登录
1. 输入手机号
2. 点击"获取验证码"
3. 输入收到的验证码
4. 点击登录
5. 登录成功

**注意：手机号登录不需要输入租户名称**

## 关键特性

### 登录方式对比

| 特性 | 账号登录 | 手机号登录 |
|------|---------|-----------|
| 租户名称 | ✅ 需要 | ❌ 不需要 |
| 滑块验证码 | ✅ 启用 | ❌ 不启用 |
| 记住我 | ✅ 支持 | ❌ 不支持 |
| 短信验证码 | ❌ 不需要 | ✅ 需要 |

### 验证规则

#### 账号登录
- 租户名称：必填
- 账号：必填
- 密码：必填

#### 手机号登录
- 手机号：必填，格式：1[3-9]\d{9}
- 验证码：必填，6位数字

## 常见问题

### Q1: 手机号登录为什么不显示租户名称？
A: 移动端设计更简洁，手机号登录时后端会自动识别用户所属租户，无需手动输入。

### Q2: 验证码收不到怎么办？
A: 
1. 检查手机号格式是否正确
2. 检查后端短信服务配置
3. 查看后端日志确认发送状态

### Q3: 滑块验证码加载失败？
A:
1. 检查网络连接
2. 确认后端验证码接口正常
3. 查看控制台错误信息

### Q4: 登录后自动退出？
A:
1. 检查 Token 是否正确保存
2. 确认后端 Token 有效期配置
3. 查看网络请求是否携带 Token
