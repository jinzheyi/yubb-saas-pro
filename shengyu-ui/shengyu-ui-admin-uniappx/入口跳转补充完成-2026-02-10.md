    uni.navigateTo({

  }

## 技术要点

### 1. 搜索框禁用输入

为了确保点击搜索框跳转而不是输入，添加了 `disabled` 属性：

```vue
<input class="search-input" disabled />
```

同时在父容器添加点击事件：

```vue
<view class="search-bar" @click="handleSearch">
```

---

### 2. 群聊类型判断

聊天页面根据 `type` 参数判断是单聊还是群聊：

```typescript
if (chatType.value === 'group') {
  // 群聊逻辑
  uni.navigateTo({
    url: `/pages/message/group-settings?groupId=${groupId.value}&name=${encodeURIComponent(name.value)}`
  })
} else {
  // 单聊逻辑
  uni.navigateTo({
    url: '/pages/message/chat-settings'
  })
}
```

---

### 3. 参数传递

使用 URL 参数传递数据：

```typescript
// 传递参数（编码中文）
url: `/pages/message/group-settings?groupId=${groupId}&name=${encodeURIComponent(name)}`

// 接收参数（解码中文）
onLoad((options : any) => {
  if (options['groupId']) {
    groupId.value = parseInt(options['groupId'])
  }
  if (options['name']) {
    name.value = decodeURIComponent(options['name'])
  }
})
```
