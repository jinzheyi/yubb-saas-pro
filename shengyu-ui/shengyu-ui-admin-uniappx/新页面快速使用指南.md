# 新页面快速使用指南

## 快速开始

### 1. 群聊设置页（3步体验）

```
消息列表 → 点击群聊 → 点击右上角"..." → 进入群聊设置
```

**操作步骤：**
1. 打开应用，进入"消息"页面
2. 点击任意群聊消息（如：产品研发团队）
3. 进入聊天页面后，点击右上角的"..."图标
4. 进入群聊设置页面

**可以体验的功能：**
- ✅ 查看群信息（群名、成员数）
- ✅ 查看前8个群成员
- ✅ 点击"查看全部群成员"
- ✅ 切换消息免打扰
- ✅ 切换置顶聊天
- ✅ 点击各种设置项（会提示开发中）

### 2. 群成员列表页（2步体验）

```
群聊设置页 → 点击"查看全部群成员"
```

**操作步骤：**
1. 在群聊设置页面
2. 点击"查看全部群成员"按钮
3. 进入群成员列表页面

**可以体验的功能：**
- ✅ 查看50个模拟群成员
- ✅ 按字母分组展示
- ✅ 使用右侧字母索引快速定位
- ✅ 搜索群成员（实时搜索）
- ✅ 查看成员角色（群主、管理员）
- ✅ 点击成员跳转到用户详情

### 3. 搜索页（1步体验）

```
消息页面 → 点击搜索框
```

**操作步骤：**
1. 在消息页面
2. 点击顶部搜索框
3. 进入搜索页面

**可以体验的功能：**
- ✅ 查看搜索历史
- ✅ 查看热门搜索
- ✅ 输入关键词实时搜索
- ✅ 搜索联系人
- ✅ 搜索群聊
- ✅ 搜索聊天记录
- ✅ 点击搜索结果跳转
- ✅ 清空搜索历史

## 常见问题

### Q1: 如何进入群聊设置页？
**A:** 在聊天页面点击右上角的"..."图标（目前需要手动添加入口）。

### Q2: 群成员列表为什么是模拟数据？
**A:** 当前使用模拟数据展示功能，后期会对接真实的后端API。

### Q3: 搜索功能支持哪些内容？
**A:** 支持搜索联系人（姓名）、群聊（群名）、聊天记录（消息内容）。

### Q4: 为什么有些功能提示"开发中"？
**A:** 这些功能的页面还未实现，会在后续版本中完成。

### Q5: 如何清空搜索历史？
**A:** 在搜索页面，点击搜索历史右上角的垃圾桶图标，确认后清空。
