# 群聊功能 - 快速测试指南

## 快速开始

### 1. 创建群聊（3步完成）

```
消息页面 → 点击右上角"+" → 选择联系人 → 点击确定
```

**操作步骤：**
1. 打开应用，进入"消息"页面
2. 点击右上角的"+"图标
3. 选择至少2个联系人（自己默认已选中）
4. 点击底部"确定(N/500)"按钮
5. 等待1秒，自动跳转到群聊页面

**预期结果：**
- ✅ 群聊名称自动生成（如：张敏、李强、王静等4人）
- ✅ 头部显示成员数量（如：4人）
- ✅ 显示5条模拟群聊消息
- ✅ 可以正常发送消息

### 2. 跨页面选择成员

```
发起群聊 → 选择联系人 → 进入"我的关注" → 选择更多 → 返回
```

**操作步骤：**
1. 在发起群聊页面选择2-3个联系人
2. 点击"我的关注"分类
3. 在我的关注页面选择更多联系人
4. 点击返回按钮
5. 查看主页面的选中状态

**预期结果：**
- ✅ 返回后选中状态保持
- ✅ 底部显示正确的选中数量
- ✅ 复选框状态正确

### 3. 群聊消息测试

```
群聊页面 → 发送文字 → 发送图片 → 发送表情
```

**操作步骤：**
1. 进入群聊页面
2. 输入文字并发送
3. 点击"+"选择相册发送图片
4. 点击表情图标发送表情

**预期结果：**
- ✅ 文字消息正常显示
- ✅ 图片消息正常显示
- ✅ 表情消息正常显示
- ✅ 消息时间正确显示

## 常见问题

### Q1: 为什么至少要选择2人？
**A:** 群聊至少需要2个成员（包括自己），如果只有1人则应该使用单聊。

### Q2: 群聊名称如何生成？
**A:** 
- 2-3人：直接显示所有人名字，用"、"分隔
- 4人及以上：显示前3人名字 + "等N人"
- 示例：`张敏、李强、王静等10人`

### Q3: 如何区分单聊和群聊？
**A:** 通过 URL 参数 `type` 区分：
- `type=single`：单聊
- `type=group`：群聊

### Q4: 群聊消息如何显示？
**A:** 
- 头像：显示发送者名字的前2个字
- 名称：不显示（通过头像区分）
- 时间：与单聊相同的时间显示规则

### Q5: 如何对接后端 API？
**A:** 参考《发起群聊功能实现说明.md》中的"后端 API 对接指南"章节。
