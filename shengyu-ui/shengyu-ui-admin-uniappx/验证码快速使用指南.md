# 验证码快速使用指南

## 一、快速开始

### 1. 配置后端地址

编辑 `config/app.config.uts`:

```typescript
// 修改为你的后端地址
export const BASE_URL = 'http://localhost:48080'
```

### 2. 启用验证码

编辑 `config/app.config.uts`:

```typescript
// 启用验证码
export const CAPTCHA_ENABLE = 'true'

// 禁用验证码（直接登录）
// export const CAPTCHA_ENABLE = 'false'
```

### 3. 运行项目

```bash
# 在 HBuilderX 中运行到手机或模拟器
# 或使用命令行
npm run dev:app
```

## 二、组件使用

### 基础用法

```vue
<template>
  <view>
    <!-- 触发按钮 -->
    <button @click="showCaptcha">显示验证码</button>
    
    <!-- 验证码组件 -->
    <slider-captcha 
      ref="captchaRef"
      captchaType="blockPuzzle"
      @success="handleSuccess"
      @fail="handleFail"
    />
  </view>
</template>

<script setup lang="uts">
import SliderCaptcha from '@/components/captcha/slider-captcha.uvue'

const captchaRef = ref<any>(null)

// 显示验证码
function showCaptcha() {
  if (captchaRef.value) {
    captchaRef.value.show()
  }
}

// 验证成功
function handleSuccess(data: any) {
  console.log('验证成功', data.captchaVerification)
  // 使用 captchaVerification 调用登录接口
}

// 验证失败
function handleFail() {
  console.log('验证失败')
}
</script>
```

### 登录页面示例

```vue
<template>
  <view class="login-container">
    <!-- 登录表单 -->
    <view class="form">
      <input v-model="username" placeholder="请输入账号" />
      <input v-model="password" type="password" placeholder="请输入密码" />
      <button @click="handleLogin">登录</button>
    </view>
    
    <!-- 验证码组件 -->
    <slider-captcha 
      ref="captchaRef"
      @success="handleCaptchaSuccess"
    />
  </view>
</template>

<script setup lang="uts">
import { login } from '@/api/login.uts'
import SliderCaptcha from '@/components/captcha/slider-captcha.uvue'
import { CAPTCHA_ENABLE } from '@/config/app.config.uts'

const username = ref<string>('')
const password = ref<string>('')
const captchaRef = ref<any>(null)
const captchaVerification = ref<string>('')

// 登录按钮点击
async function handleLogin() {
  // 验证表单
  if (!username.value || !password.value) {
    uni.showToast({ title: '请输入账号密码', icon: 'none' })
    return
  }
  
  // 判断是否需要验证码
  if (CAPTCHA_ENABLE === 'true') {
    // 显示验证码
    if (captchaRef.value) {
      captchaRef.value.show()
    }
  } else {
    // 直接登录
    await doLogin('')
  }
}

// 验证码成功回调
function handleCaptchaSuccess(data: any) {
  captchaVerification.value = data.captchaVerification
  doLogin(data.captchaVerification)
}

// 执行登录
async function doLogin(verification: string) {
  try {
    const result = await login({
      username: username.value,
      password: password.value,
      captchaVerification: verification
    })
    
    uni.showToast({ title: '登录成功', icon: 'success' })
    // 跳转到首页
    uni.switchTab({ url: '/pages/index/index' })
  } catch (e) {
    console.error('登录失败', e)
  }
}
</script>
```

## 五、常见问题

### 1. 验证码不显示

**原因**: 后端接口地址不正确或网络问题

**解决**:
```typescript
// 检查 config/app.config.uts 中的 BASE_URL
export const BASE_URL = 'http://your-backend-url'

// 确保后端服务已启动
// 检查控制台是否有错误信息
```

### 2. 滑动不流畅

**原因**: 触摸事件冲突或性能问题

**解决**:
- 确保验证码组件在最上层（z-index 足够大）
- 检查是否有其他元素遮挡
- 减少页面其他动画效果

### 3. 验证总是失败

**原因**: 坐标计算不准确或后端配置问题

**解决**:
```typescript
// 检查坐标转换逻辑
const realDistance = Math.round(moveDistance * 310 / 310)

// 查看后端日志，确认接收到的坐标是否正确
// 检查后端验证码配置
```

### 4. 加密报错

**原因**: UniApp X 不支持 crypto-js

**解决**:
```typescript
// 当前使用 Base64 临时方案
// 生产环境建议：
// 1. 使用原生加密插件
// 2. 让后端支持明文传输（仅开发环境）
```
