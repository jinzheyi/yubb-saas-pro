# 主页面联系人选择 - 修复说明

## 问题描述

在发起群聊主页面（initiate-group.uvue）选择通讯录联系人后，从子页面（如"我的关注"）返回时，主页面选择的联系人数据失效，复选框状态丢失。

## 问题原因

### 1. 选择操作未同步到全局状态

**原代码**：
```typescript
function handleSelect(item: any) {
  // 当前用户不能取消选中
  if (item.isCurrentUser && item.selected) {
    uni.showToast({
      title: '不能取消选择自己',
      icon: 'none'
    })
    item.selected = true
    return
  }
  
  console.log('选择联系人:', item.name, '选中状态:', item.selected)
  // ❌ 只打印日志，没有同步到全局状态
}
```

**问题**：
- `contact-selector` 组件内部切换了 `item.selected` 状态
- 但父组件的 `handleSelect` 函数没有将变化同步到全局状态
- 导致全局状态和本地状态不一致

### 2. 缺少状态同步机制

**原代码**：
```typescript
onLoad(() => {
  startSelection()
  const currentUser = contactList.value.find(c => c.isCurrentUser)
  if (currentUser) {
    addMember(currentUser)
  }
  // ❌ 没有同步选中状态
})

// ❌ 没有 onShow 生命周期
```

**问题**：
- 从子页面返回时，没有 `onShow` 生命周期来同步状态
- 子页面选择的成员已经在全局状态中，但主页面的复选框没有更新

## 修复方案

### 1. 导入必要的全局状态函数

```typescript
import { 
  startSelection, 
  endSelection, 
  getSelectedMembers, 
  getSelectedCount,
  addMember,
  toggleMember,      // ✅ 新增：切换成员选中状态
  isMemberSelected   // ✅ 新增：查询成员是否选中
} from '../../store/group-selection.uts'
```

### 2. 修复 handleSelect 函数

```typescript
function handleSelect(item: any) {
  // 当前用户不能取消选中
  if (item.isCurrentUser && !item.selected) {  // ✅ 修改判断条件
    uni.showToast({
      title: '不能取消选择自己',
      icon: 'none'
    })
    // 强制保持选中状态
    item.selected = true
    return
  }
  
  // ✅ 同步到全局状态
  toggleMember(item)
  // ✅ 确保本地状态与全局状态一致
  item.selected = isMemberSelected(item.id)
  
  console.log('选择联系人:', item.name, '选中状态:', item.selected)
}
```

**关键改进**：
1. 调用 `toggleMember(item)` 将选择操作同步到全局状态
2. 调用 `isMemberSelected(item.id)` 确保本地状态与全局状态一致
3. 修改判断条件：`!item.selected` 表示尝试取消选中

### 3. 添加状态同步函数

```typescript
// 同步本地选中状态与全局状态
function syncSelectionState() {
  for (let i = 0; i < contactList.value.length; i++) {
    contactList.value[i].selected = isMemberSelected(contactList.value[i].id)
  }
}
```

**功能**：
- 遍历所有联系人
- 从全局状态查询每个联系人的选中状态
- 更新本地 `selected` 属性

### 4. 在生命周期中调用同步函数

```typescript
// 页面加载时初始化选择模式
onLoad(() => {
  startSelection()
  // 默认添加当前用户
  const currentUser = contactList.value.find(c => c.isCurrentUser)
  if (currentUser) {
    addMember(currentUser)
  }
  // ✅ 同步选中状态
  syncSelectionState()
})

// ✅ 页面显示时同步选中状态（从子页面返回时）
onShow(() => {
  syncSelectionState()
})

// 页面卸载时清空选择状态（如果没有确认）
onUnload(() => {
  endSelection()
})
```

**关键改进**：
1. `onLoad` 时调用 `syncSelectionState()` 初始化状态
2. 添加 `onShow` 生命周期，从子页面返回时重新同步状态
