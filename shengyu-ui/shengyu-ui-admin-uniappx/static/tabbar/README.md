# TabBar 图标说明

本目录需要放置底部导航栏的图标文件。

## 所需图标文件

请准备以下 8 个图标文件（建议尺寸：81x81 像素）：

### 消息
- `message.png` - 消息图标（未选中状态）
- `message-active.png` - 消息图标（选中状态）

### 通讯录
- `contacts.png` - 通讯录图标（未选中状态）
- `contacts-active.png` - 通讯录图标（选中状态）

### 工作台
- `workbench.png` - 工作台图标（未选中状态）
- `workbench-active.png` - 工作台图标（选中状态）

### 我的
- `profile.png` - 我的图标（未选中状态）
- `profile-active.png` - 我的图标（选中状态）

## 图标设计建议

- 未选中状态：使用灰色 (#999999)
- 选中状态：使用主题色 (#667eea)
- 图标风格：简洁、清晰、易识别
- 文件格式：PNG（支持透明背景）

## 临时方案

如果暂时没有图标，可以：
1. 使用 logo.png 作为临时图标
2. 或者从 iconfont、阿里图标库等下载合适的图标
