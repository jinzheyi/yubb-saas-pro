# 验证码配置 - 快速参考

## 🚀 快速配置

### 启用验证码（默认）
```typescript
// config/app.config.uts
export const CAPTCHA_ENABLE = 'true'
```

### 禁用验证码
```typescript
// config/app.config.uts
export const CAPTCHA_ENABLE = 'false'
```

---

## 📋 配置说明

| 配置值 | 效果 | 适用场景 |
|--------|------|---------|
| `'true'` | 账号登录显示验证码 | 生产环境 |
| `'false'` | 账号登录不显示验证码 | 开发/测试环境 |

**注意**：手机号登录不受此配置影响，始终不显示滑块验证码。

---

## 🔄 修改步骤

1. 打开文件：`config/app.config.uts`
2. 找到配置项：`CAPTCHA_ENABLE`
3. 修改值：`'true'` 或 `'false'`
4. 保存文件
5. 重启应用

---

## ✅ 验证方式

### 启用验证码
```
1. 选择账号登录
2. 输入账号、密码
3. 点击登录
4. 应该显示滑块验证码 ✅
```

### 禁用验证码
```
1. 选择账号登录
2. 输入账号、密码
3. 点击登录
4. 应该直接登录，不显示验证码 ✅
```

## ⚡ 常见问题

### Q: 为什么使用字符串 `'false'` 而不是布尔值 `false`？
A: 严格参考 PC 端实现，PC 端从环境变量读取的是字符串类型。

### Q: 手机号登录会显示验证码吗？
A: 不会，手机号登录不使用滑块验证码，仅使用短信验证码。

### Q: 修改配置后需要重启应用吗？
A: 是的，需要重启应用才能生效。
