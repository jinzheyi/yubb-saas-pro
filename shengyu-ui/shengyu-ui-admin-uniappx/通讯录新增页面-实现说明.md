# 通讯录新增页面实现说明

## 概述

根据原型图实现了6个通讯录相关页面，所有页面使用假名数据，不显示底部导航栏，采用统一的蓝色主题（#1677FF）。所有页面均支持选择模式，用于发起群聊时选择成员。

## 已实现页面

### 1. 组织结构页面 (`pages/contacts/organization.uvue`)

**功能特点**:
- ✅ 树形结构展示组织架构
- ✅ 支持展开/收起组织和部门
- ✅ 显示组织、部门、成员三级结构
- ✅ 点击成员跳转到用户详情页

**数据结构**:
```typescript
{

    name: '科技创新集团有限公司',
    count: 362

      id: 'org1',

      count: 63,
```

### 2. 用户详情页面 (`pages/contacts/user-detail.uvue`)

**功能特点**:
- ✅ 显示用户基本信息（姓名、手机、座机、邮箱、职级、部门）
- ✅ 右上角"更多"菜单（关注、导入手机、分享名片）
- ✅ 底部操作按钮（消息、通话）
- ✅ 未设置的字段显示灰色"未设置"

**数据结构**:
```typescript
{
  userName: '张敏',
  userInfo: {
    company: '科技创新集团有限公司',
    mobile: '187-2096-9685',
    phone: '',
    otherPhone: '',
    email: '',
    level: '',
    department: '数字科技有限公司/软件研发事业部'
  }

```

**路由**: `/pages/contacts/user-detail?name=张敏`

**入口**: 
- 组织结构页面 -> 点击成员
- 我的关注页面 -> 点击联系人
- 我的部门页面 -> 点击成员
- 搜索结果页面 -> 点击联系人

## 设计规范

### 1. 配色方案

**主题色**:
- 企业红: `#C8161D` / `#D71921` / `#D32F2F` / `#C8102E`
- 背景色: `#F5F5F7` / `#F2F2F7` / `#F9FAFB`
- 卡片背景: `#FFFFFF`

**文字颜色**:
- 主标题: `#1F2329` / `#1F2937`
- 副标题: `#646A73` / `#6B7280`
- 辅助文字: `#8F959E` / `#9CA3AF`
- 占位文字: `#C1C4C9`

**功能色**:
- 蓝色: `#0ea5e9` (链接、图标)
- 绿色: `#10b981` (成功)
- 橙色: `#f97316` (警告)
- 粉色: `#fb7185` (强调)

### 2. 布局规范

**头部导航栏**:
- 高度: 44px
- 背景色: 企业红
- 文字颜色: 白色
- 左侧: 返回按钮 + 返回文字
- 中间: 页面标题
- 右侧: 操作按钮（可选）

**搜索栏**:
- 高度: 36px
- 背景色: `#F2F3F5`
- 圆角: 8px / 12px
- 图标: 搜索图标 + 输入框

**列表项**:
- 高度: 自适应（最小 60px）
- 内边距: 12px 16px
- 分割线: 0.5px `#F5F7FA`
- 激活状态: 背景色 `#F9FAFB`

**头像**:
- 尺寸: 40px / 48px
- 圆角: 50%（圆形）
- 文字大小: 13px / 14px
- 文字颜色: 白色

### 3. 交互规范

**点击反馈**:
- 列表项点击: 背景色变化
- 按钮点击: 透明度变化或缩放
- 长按: 显示菜单

**页面跳转**:
- 使用 `uni.navigateTo()` 进行页面跳转
- 传递参数使用 URL 参数
- 返回使用 `uni.navigateBack()`

**提示信息**:
- 成功: `uni.showToast({ title: '操作成功', icon: 'success' })`
- 失败: `uni.showToast({ title: '操作失败', icon: 'none' })`
- 加载: `uni.showToast({ title: '加载中...', icon: 'loading' })`
