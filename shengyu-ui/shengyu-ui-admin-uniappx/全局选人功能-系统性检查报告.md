## 一、核心问题修复

### ❌ 问题：ID 冲突导致数据丢失

**现象**：
- 从发起群聊进入"我的关注"选择成员
- 返回上一级再次进入"我的关注"
- 之前选中的数据丢失

**根本原因**：
不同页面使用了相同的成员 ID（1-10），导致全局状态管理中的去重逻辑失效。

**修复方案**：
重新分配 ID 范围，确保全局唯一性：
- 我的关注：2001-2007
- 组织结构：3001-3003
- 我的部门：4001-4010
- 群组成员：5000+（按群组分段）

**修复状态**：✅ 已完成
