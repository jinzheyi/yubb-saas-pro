## 技术要点

### 1. 搜索框禁用输入

为了确保点击搜索框跳转而不是输入，使用了以下方案：

```vue
<!-- 父容器添加点击事件 -->
<view class="search-bar" @click="handleSearch">
  <!-- input 添加 disabled 属性 -->
  <input class="search-input" disabled />
</view>
```

**优点：**
- 用户点击搜索框时直接跳转
- 不会触发键盘弹出
- 保持搜索框的视觉效果

---

### 2. 群聊类型判断

聊天页面根据 `type` 参数判断是单聊还是群聊：

```typescript
function handleToSettings() {
  if (chatType.value === 'group') {
    // 群聊跳转到群聊设置页
    uni.navigateTo({
      url: `/pages/message/group-settings?groupId=${groupId.value}&name=${encodeURIComponent(name.value)}`
    })
  } else {
    // 单聊跳转到聊天设置页
    uni.navigateTo({
      url: '/pages/message/chat-settings'
    })
  }
}
```

**优点：**
- 同一个按钮，不同的跳转逻辑
- 代码复用性高
- 易于维护

---

### 3. 参数传递

使用 URL 参数传递数据，支持中文编码：

```typescript
// 传递参数（编码中文）
url: `/pages/message/group-settings?groupId=${groupId}&name=${encodeURIComponent(name)}`

// 接收参数（解码中文）
onLoad((options : any) => {
  if (options['groupId']) {
    groupId.value = parseInt(options['groupId'])
  }
  if (options['name']) {
    name.value = decodeURIComponent(options['name'])
  }
})
```

**注意事项：**
- 中文参数必须使用 `encodeURIComponent` 编码
- 接收时使用 `decodeURIComponent` 解码
- 数字参数需要使用 `parseInt` 转换
