- `pages/contacts/my-department.uvue`

### 3. ✅ 主页面联系人选择修复

**问题**：主页面选择的联系人数据失效，从子页面返回后复选框状态丢失

**原因**：
1. `handleSelect` 函数没有将选择操作同步到全局状态
2. 缺少 `onShow` 生命周期来同步状态

**修复**：
- 导入 `toggleMember` 和 `isMemberSelected` 函数
- 修复 `handleSelect` 函数，调用 `toggleMember()` 同步全局状态
- 添加 `syncSelectionState()` 函数
- 在 `onLoad` 和 `onShow` 中调用同步函数
