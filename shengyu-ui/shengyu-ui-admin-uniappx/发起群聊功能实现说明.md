# 发起群聊功能实现说明

## 功能概述

实现了完整的群聊创建功能，支持从多个来源选择成员，并在页面间导航时保持选择状态。

## 核心特性

### 1. 全局选择状态管理

使用全局 store (`store/group-selection.uts`) 管理选中的成员，确保在不同页面间导航时数据不丢失。

**主要功能：**
- `startSelection()` - 开始选择模式
- `endSelection()` - 结束选择模式并清空数据
- `toggleMember(member)` - 切换成员选中状态
- `addMembers(members)` - 批量添加成员
- `removeMembers(memberIds)` - 批量移除成员
- `isMemberSelected(memberId)` - 检查成员是否已选中
- `getSelectedCount()` - 获取选中数量
- `getSelectedMembers()` - 获取所有选中成员

### 2. 多来源成员选择

支持从以下来源选择成员：

#### 2.1 直接联系人列表
- 页面：`pages/contacts/initiate-group.uvue`
- 显示所有联系人，支持直接勾选
- 默认选中当前登录用户（不可取消）

#### 2.2 我的关注
- 页面：`pages/contacts/my-following.uvue`
- 显示关注的用户列表
- 选择模式下显示复选框

#### 2.3 组织结构
- 页面：`pages/contacts/organization.uvue`
- 支持层级选择：
  - 选中组织 → 自动选中所有部门和成员
  - 选中部门 → 自动选中所有成员
  - 选中成员 → 单独选中
- 双向级联：子项选中状态会影响父项状态

#### 2.4 我的部门
- 页面：`pages/contacts/my-department.uvue`
- 显示当前用户所在部门的成员
- 支持部门层级展开/收起

#### 2.5 我的群组
- 页面：`pages/contacts/my-groups.uvue`
- 点击群组后跳转到群成员列表
- 群成员页面：`pages/contacts/group-members.uvue`
- 根据群组ID生成不同数量的成员

### 3. 选择状态持久化

**实现机制：**

1. **页面加载时（onLoad）**
   - 检查是否为选择模式（`mode=select` 参数）
   - 调用 `syncSelectionState()` 从全局 store 恢复选中状态

2. **页面显示时（onShow）**
   - 从其他页面返回时重新同步选中状态
   - 确保显示最新的选择结果

3. **选择操作时**
   - 调用全局 store 的 `toggleMember()` 更新全局状态
   - 同步更新本地 UI 状态（`member.selected`）

4. **确认返回时**
   - 不清空全局状态，直接 `uni.navigateBack()`
   - 数据保留在全局 store 中

5. **退出创建群聊时**
   - 在 `initiate-group.uvue` 的 `onUnload` 中调用 `endSelection()`
   - 清空所有选择数据

// 切换组织选中（批量操作）
function toggleOrgSelect(org: any) {
  org.selected = !org.selected
  
  // 收集所有成员
  const allMembers: any[] = []
  for (let i = 0; i < org.departments.length; i++) {
    const dept = org.departments[i]
    dept.selected = org.selected
    for (let j = 0; j < dept.members.length; j++) {
      allMembers.push(dept.members[j])
      dept.members[j].selected = org.selected
    }
  }
  
  // 批量更新全局状态
  if (org.selected) {
    addMembers(allMembers)
  } else {
    const memberIds = allMembers.map(m => m.id)
    removeMembers(memberIds)
  }
}

function toggleDeptSelect(org: any, dept: any) {

## 数据流程

```
1. 用户进入发起群聊页面
   ↓
2. 调用 startSelection() 初始化全局状态
   ↓
3. 用户点击分类（如"我的关注"）
   ↓
4. 跳转到对应页面，传递 mode=select 参数
   ↓
5. 子页面加载时调用 syncSelectionState() 恢复选中状态
   ↓
6. 用户选择/取消选择成员
   ↓
7. 调用 toggleMember() 更新全局状态
   ↓
8. 用户点击"确定"返回上一页
   ↓
9. 上一页 onShow 时重新同步选中状态
   ↓
10. 用户可以继续选择或返回主页面
   ↓
11. 用户点击"确认"创建群聊或返回退出
   ↓
12. 调用 endSelection() 清空全局状态
```

## 关键技术点

### 1. 去重机制

全局 store 中的 `addMember()` 函数会根据 `id` 去重：

```typescript
export function addMember(member: any) {
  const exists = selectedMembers.value.some(m => m.id === member.id)
  if (!exists) {
    selectedMembers.value.push({
      id: member.id,
      name: member.name,
      role: member.role,
      avatarText: member.avatarText,
      avatarBg: member.avatarBg
    })
  }
}
```

### 2. 双向同步

- **全局 → 本地**：`syncSelectionState()` 在页面加载/显示时调用
- **本地 → 全局**：`toggleMember()` 在用户操作时调用

### 3. 生命周期管理

- `onLoad`：初始化，恢复状态
- `onShow`：重新同步状态（从子页面返回时）
- `onUnload`：清理资源（仅在主入口页面）

## 注意事项

1. **当前用户不可取消**：默认选中当前登录用户，且不允许取消选中
2. **最少 2 人**：创建群聊至少需要 2 人（包含当前用户）
3. **假名数据**：所有联系人使用假名（张敏、李强等），避免真实个人信息
4. **参数传递**：使用 `options['key']` 语法而非 `options.get('key')`，避免类型错误
5. **底部导航栏**：所有选择页面不显示底部导航栏
