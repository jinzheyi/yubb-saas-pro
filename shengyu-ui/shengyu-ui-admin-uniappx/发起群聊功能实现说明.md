# 发起群聊功能实现说明

## 概述
本文档说明了群聊创建功能的完整实现，包括成员选择、群聊创建、群聊页面展示等功能。实现遵循后端 API 对接的设计原则，便于后期集成真实接口。

## 功能特性

### 1. 成员选择
- ✅ 支持从通讯录选择成员
- ✅ 支持从我的关注、组织架构、我的部门等分类选择
- ✅ 全局状态管理，跨页面保持选中状态
- ✅ 当前用户默认选中且不可取消
- ✅ 至少需要选择2人（包括自己）才能创建群聊
- ✅ 实时显示已选择人数

### 2. 群聊创建
- ✅ 自动生成群聊名称（前3人名字，超过3人显示"等N人"）
- ✅ 创建群聊数据结构兼容后端 API
- ✅ 支持群聊基本设置（允许成员邀请、加群审批、全员禁言等）
- ✅ 创建成功后自动跳转到群聊页面

### 3. 群聊页面
- ✅ 复用单聊页面组件（chat.uvue）
- ✅ 通过参数区分单聊和群聊
- ✅ 群聊显示成员数量
- ✅ 支持所有消息类型（文字、图片、视频、语音、文件、位置、表情等）
- ✅ 模拟群聊消息数据

{

  // 成员列表

### 3. 群聊名称生成规则

```typescript
function generateGroupName(members: any[]): string {
  if (members.length === 0) return '群聊'
  if (members.length <= 3) {
    return members.map(m => m.name).join('、')
  }
  const firstThree = members.slice(0, 3).map(m => m.name).join('、')
  return `${firstThree}等${members.length}人`
}
```

示例：
- 2人：`张敏、李强`
- 3人：`张敏、李强、王静`
- 4人：`张敏、李强、王静等4人`
- 10人：`张敏、李强、王静等10人`

### 4. 页面组件复用

#### chat.uvue 支持单聊和群聊
通过 `chatType` 变量区分：
```typescript
const chatType = ref('single')  // 'single' | 'group'
const groupId = ref(0)
const memberCount = ref(0)

onLoad((options: any) => {
  if (options['type']) {
    chatType.value = options['type']
  }
  if (options['groupId']) {
    groupId.value = parseInt(options['groupId'])
  }
  if (options['memberCount']) {
    memberCount.value = parseInt(options['memberCount'])
  }
  
  if (chatType.value === 'group') {
    loadGroupMessages()
  }
})
```

## 后端 API 对接指南

### 1. 创建群聊 API

#### 请求
```typescript
POST /api/group/create

{
  "groupName": "张敏、李强、王静等4人",
  "groupType": "normal",
  "memberIds": [1, 2001, 2002, 2003],
  "settings": {
    "allowMemberInvite": true,
    "needApproval": false,
    "muteAll": false
  }
}
```

#### 响应
```typescript
{
  "code": 200,
  "message": "success",
  "data": {
    "groupId": 10001,
    "groupName": "张敏、李强、王静等4人",
    "memberCount": 4,
    "createTime": 1707552000000
  }
}
```

#### 前端调用示例
```typescript
// 在 initiate-group.uvue 的 handleConfirm 函数中
import { request } from '../../utils/request.uts'

function handleConfirm() {
  const selectedMembers = getSelectedMembers()
  
  const groupData = {
    groupName: generateGroupName(selectedMembers),
    groupType: 'normal',
    memberIds: selectedMembers.map(m => m.id),
    settings: {
      allowMemberInvite: true,
      needApproval: false,
      muteAll: false
    }
  }
  
  // 调用后端 API
  request({
    url: '/api/group/create',
    method: 'POST',
    data: groupData
  }).then((res: any) => {
    const groupId = res.data.groupId
    const groupName = res.data.groupName
    const memberCount = res.data.memberCount
    
    uni.showToast({
      title: '创建成功',
      icon: 'success'
    })
    
    // 跳转到群聊页面
    uni.redirectTo({
      url: `/pages/message/chat?type=group&groupId=${groupId}&name=${encodeURIComponent(groupName)}&memberCount=${memberCount}`
    })
    
    endSelection()
  }).catch((err: any) => {
    uni.showToast({
      title: err.message || '创建失败',
      icon: 'none'
    })
  })
}
```

#### 前端调用示例
```typescript
// 在 chat.uvue 的 loadGroupMessages 函数中
function loadGroupMessages() {
  request({
    url: '/api/group/messages',
    method: 'GET',
    data: {
      groupId: groupId.value,
      page: 1,
      pageSize: 20
    }
  }).then((res: any) => {
    const messageList = res.data.list.map((msg: any) => {
      return {
        id: msg.id,
        senderId: msg.senderId,
        receiverId: groupId.value.toString(),
        type: msg.type,
        content: msg.content,
        isSelf: msg.senderId === 'me', // 判断是否是自己发送的
        time: new Date(msg.timestamp).toLocaleString(),
        timestamp: msg.timestamp,
        showTime: false,
        avatarText: msg.senderName.substring(0, 2),
        avatarBg: generateAvatarColor(msg.senderId),
        status: msg.status
      }
    })
    
    messages.value = messageList
    scrollToBottom()
  })
}
```
