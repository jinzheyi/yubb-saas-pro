## 常见问题排查

### 问题1：点击搜索框没有反应

**可能原因：**
- 搜索框没有添加点击事件
- 搜索框被其他元素遮挡
- JavaScript 错误导致事件未绑定

**排查步骤：**
1. 检查控制台是否有错误
2. 检查搜索框是否有 `@click` 事件
3. 检查 `handleSearch()` 函数是否存在

---

### 问题2：跳转到错误的页面

**可能原因：**
- URL 参数错误
- 路由配置错误
- 页面路径错误

**排查步骤：**
1. 检查 `pages.json` 中的路由配置
2. 检查跳转 URL 是否正确
3. 检查参数传递是否正确

---

### 问题3：页面显示不正常

**可能原因：**
- 参数未正确接收
- 数据未正确加载
- 样式问题

**排查步骤：**
1. 检查 `onLoad()` 函数是否正确接收参数
2. 检查数据是否正确加载
3. 检查控制台是否有错误
