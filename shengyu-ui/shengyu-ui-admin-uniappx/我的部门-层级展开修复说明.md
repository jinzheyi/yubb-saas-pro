# 我的部门 - 层级展开修复说明

## 问题描述

"我的部门"页面的二级组织结构（"数字科技有限公司"和"软件研发事业部"）无法展开收缩，图标是静态的，点击无效。

## 问题原因

原实现中，二级和三级部门是静态显示的，没有绑定点击事件和展开状态：

```vue
<!-- 原代码 - 静态显示 -->
<view class="dept-child">
  <text class="iconfont child-icon">&#xeaf3;</text>  <!-- 固定图标 -->
  <text class="dept-child-text">数字科技有限公司(30)</text>
</view>
<view class="dept-child dept-child-active">
  <text class="iconfont child-icon">&#xeaf3;</text>  <!-- 固定图标 -->
  <text class="dept-child-text dept-child-text-active">软件研发事业部(30)</text>
</view>
```

## 修复方案

### 1. 添加展开状态管理

```typescript
// 部门层级展开状态
const deptExpanded = ref(true)          // 一级：科技创新集团有限公司
const subDept1Expanded = ref(true)      // 二级：数字科技有限公司
const subDept2Expanded = ref(true)      // 三级：软件研发事业部
```

### 2. 添加切换函数

```typescript
function toggleDeptExpand() {
  deptExpanded.value = !deptExpanded.value
}

function toggleSubDept1() {
  subDept1Expanded.value = !subDept1Expanded.value
}

function toggleSubDept2() {
  subDept2Expanded.value = !subDept2Expanded.value
}
```

### 3. 更新模板结构

```vue
<view class="dept-hierarchy">
  <!-- 一级部门 -->
  <view class="dept-node" @click="toggleDeptExpand">
    <text class="dept-node-text">科技创新集团有限公司(30)</text>
    <text class="iconfont expand-icon">{{ deptExpanded ? '\ueaf5' : '\ueaf3' }}</text>
  </view>
  
  <!-- 二级部门容器 -->
  <view v-if="deptExpanded" class="dept-children">
    <!-- 二级部门1 - 可点击展开收缩 -->
    <view class="dept-child" @click="toggleSubDept1">
      <text class="iconfont child-icon">{{ subDept1Expanded ? '\ueaf5' : '\ueaf3' }}</text>
      <text class="dept-child-text">数字科技有限公司(30)</text>
    </view>
    
    <!-- 三级部门容器 - 只在二级部门1展开时显示 -->
    <view v-if="subDept1Expanded" class="dept-grandchildren">
      <view class="dept-child dept-child-active" @click="toggleSubDept2">
        <text class="iconfont child-icon">{{ subDept2Expanded ? '\ueaf5' : '\ueaf3' }}</text>
        <text class="dept-child-text dept-child-text-active">软件研发事业部(30)</text>
      </view>
    </view>
  </view>
</view>

<!-- 成员列表 - 只在所有层级都展开时显示 -->
<view v-if="deptExpanded && subDept1Expanded && subDept2Expanded" class="member-list">
  <!-- 成员列表内容 -->
</view>
```

## 层级结构

```
科技创新集团有限公司(30)  [一级 - deptExpanded]
  └─ 数字科技有限公司(30)  [二级 - subDept1Expanded]
       └─ 软件研发事业部(30)  [三级 - subDept2Expanded]
            └─ 成员列表（10人）
```

## 展开收缩逻辑

### 一级部门收缩
- 点击"科技创新集团有限公司"
- 隐藏所有二级、三级部门和成员列表

### 二级部门收缩
- 点击"数字科技有限公司"
- 隐藏三级部门和成员列表
- 一级部门保持展开

### 三级部门收缩
- 点击"软件研发事业部"
- 隐藏成员列表
- 一级和二级部门保持展开

## 图标说明

- `\ueaf3` (加号) - 收缩状态
- `\ueaf5` (减号) - 展开状态

图标根据展开状态动态切换：
```typescript
{{ subDept1Expanded ? '\ueaf5' : '\ueaf3' }}
```

## 成员列表显示条件

成员列表只在所有层级都展开时显示：

```vue
<view v-if="deptExpanded && subDept1Expanded && subDept2Expanded" class="member-list">
```

这确保了：
1. 收缩任何一级部门，成员列表都会隐藏
2. 只有完整展开到三级部门时，才显示成员
