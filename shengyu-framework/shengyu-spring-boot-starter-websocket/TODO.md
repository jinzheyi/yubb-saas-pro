## 注意事项

1. **开发规范**
   - 遵循项目代码规范
   - 编写清晰的注释
   - 提交规范的 Git Commit

2. **测试要求**
   - 每个功能必须有单元测试
   - 核心功能必须有集成测试
   - 上线前必须进行压力测试

3. **文档要求**
   - 每个功能必须有接口文档
   - 重要功能必须有设计文档
   - 复杂逻辑必须有流程图

4. **性能要求**
   - 单机支持 50w+ 连接
   - 消息延迟 < 100ms
   - 消息发送成功率 > 99.9%

5. **安全要求**
   - 所有接口必须认证
   - 敏感数据必须加密
   - 必须实现防刷机制
