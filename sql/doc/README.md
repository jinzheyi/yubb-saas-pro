## 🚀 快速开始（开发联调）

### 1) WebSocket 服务地址

- 服务端端口：`9000`（`shengyu.netty.port`）
- WebSocket Path：`/ws`（`shengyu.netty.webSocketPath`）
- 示例：`ws://localhost:9000/ws`

### 2) 协议与关键约束（务必遵循）

- **[Long/ID 精度]** JSON 场景下所有 `Long`（`messageId/sequence/chatId/groupId/userId/tenantId/...`）必须按 `string` 处理，禁止转 `number` 后参与去重/索引。
- **[端侧约束汇总]** uni-app-x/UTS 已知限制与踩坑清单：`sql/doc/uni-app-x开发资料-摘录.md`（重点看 6.1）
- **[协商顺序]** 连接建立后必须先完成 `PROBE`，再发送 `AUTH_REQ`（严格模式下未 PROBE 会被关闭）。
- **[codec 绑定]** 一个连接只绑定一个 `codec`（`json` 或 `pb`），绑定后不得切换；切换必须重连。
- **[载体约束]**
  - `codec=json`：业务消息走 TextFrame
  - `codec=pb`：除 `PROBE/PROBE_RESP/CLOSE` 外，业务消息必须走 BinaryFrame

### 3) 推荐阅读顺序

1. `IM即时通讯架构设计文档-v2.0.md`：理解协议、鉴权与可靠性闭环
2. `IM即时通讯开发任务清单-v2.0.md`：按 Milestone 推进与验收
