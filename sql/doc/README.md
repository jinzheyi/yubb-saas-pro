## 💡 使用技巧

### 对于开发者
1. **新对话开始时**：只需说"引用 sql/doc/IM即时通讯逻辑设计文档-v1.0.md，继续下一步"
2. **换电脑时**：文档包含所有上下文，AI能立即理解项目状态
3. **查看进度**：随时说"查看进度"获取详细报告
4. **跳过任务**：不想做某个任务时说"跳过任务 X.X.X"

### 对于AI
1. **首次接手**：先读"AI快速开始指南"章节
2. **继续开发**：直接查看"下一步待办任务"
3. **完成任务**：必须更新文档状态和版本号
4. **遇到问题**：查看文档中的详细设计章节
