## 📝 功能说明

### 聊天记录搜索架构

```
chat-history.uvue (前端页面)
    ↓
api/message.uts (API 封装)
    ↓
AppImMessageController (控制器)
    ↓
ImMessageService (业务逻辑)
    ↓
ImMessageMapper (数据访问)
    ↓
im_message (数据库表)
```

**关键设计点**:
1. ✅ 只搜索文本消息（messageType = 1）
2. ✅ 支持关键词模糊匹配（LIKE 查询）
3. ✅ 支持时间范围筛选（可选）
4. ✅ 权限验证：只能搜索自己参与的会话
5. ✅ 分页查询，按时间倒序排列
