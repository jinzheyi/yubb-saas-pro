**测试步骤**:

2. 进入某个群聊
3. 点击群设置 → 群文件

## 🐛 已知问题和注意事项

### 1. 文件上传大小限制

- 默认限制：100MB
- 如需修改，请在 `application.yml` 中配置：

```yaml
spring:
  servlet:
    multipart:
      max-file-size: 100MB
      max-request-size: 100MB
```

### 2. 文件存储路径

- 文件存储在：`im/group/{groupId}/`
- 确保文件服务配置正确

### 3. 搜索性能

- 当消息量很大时（>10万条），搜索可能较慢
- 建议后续添加全文索引优化

### 4. 文件删除

- 删除群文件关联记录时，不会删除 `infra_file` 中的实际文件
- 这是为了防止文件被其他地方引用
