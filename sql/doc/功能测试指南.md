## 🧪 群文件功能测试

### 1. 文件上传测试

**场景1: 聊天页面上传图片**
1. 打开群聊 → 点击"+" → 选择"相册" → 选择图片 → 发送
2. ✅ 验证: 图片消息发送成功
3. ✅ 验证: 控制台输出"图片已保存到群文件"
4. ✅ 验证: 在群文件列表中能看到该图片

**场景2: 聊天页面上传视频**
1. 打开群聊 → 点击"+" → 选择"视频" → 选择视频 → 发送
2. ✅ 验证: 视频消息发送成功
3. ✅ 验证: 在群文件列表中能看到该视频

**场景3: 聊天页面上传文件**
1. 打开群聊 → 点击"+" → 选择"文件" → 选择文件 → 发送
2. ✅ 验证: 文件消息发送成功
3. ✅ 验证: 在群文件列表中能看到该文件

**场景4: 单聊上传文件（验证不保存）**
1. 打开单聊 → 上传任意文件 → 发送
2. ✅ 验证: 文件消息发送成功
3. ✅ 验证: 群文件列表中不会出现该文件

### 2. 文件列表测试

**场景1: 查看群文件列表**
1. 进入群聊 → 点击右上角设置 → 选择"群文件"
2. ✅ 验证: 显示所有群文件
3. ✅ 验证: 文件按日期分组（今天、昨天、日期）
4. ✅ 验证: 显示文件名、大小、上传者

**场景2: 文件类型筛选**
1. 在群文件页面 → 点击"图片"标签
2. ✅ 验证: 只显示图片类型文件
3. 点击"视频"标签
4. ✅ 验证: 只显示视频类型文件
5. 点击"文件"标签
6. ✅ 验证: 只显示文档类型文件

### 3. 文件预览和播放测试

**场景1: 图片预览**
1. 在群文件列表中 → 点击一张图片
2. ✅ 验证: 打开图片预览
3. ✅ 验证: 可以缩放图片

**场景2: 视频播放**
1. 在群文件列表中 → 点击一个视频
2. ✅ 验证: 跳转到视频播放器页面
3. ✅ 验证: 视频自动开始播放
4. ✅ 验证: 可以暂停/播放
5. ✅ 验证: 可以拖动进度条
6. ✅ 验证: 可以全屏播放

**场景3: 文件下载**
1. 在群文件列表中 → 点击一个文档文件
2. ✅ 验证: 开始下载文件
3. ✅ 验证: 下载成功后显示提示
4. ✅ 验证: 可以打开文件预览

### 4. 文件删除测试

**场景1: 上传者删除自己的文件**
1. 使用上传者账号登录 → 在群文件列表中 → 长按文件 → 选择"删除" → 确认
2. ✅ 验证: 删除成功
3. ✅ 验证: 文件从列表中消失

**场景2: 群主删除他人的文件**
1. 使用群主账号登录 → 选择其他成员上传的文件 → 删除
2. ✅ 验证: 删除成功

**场景3: 普通成员删除他人的文件（应该失败）**
1. 使用普通成员账号登录 → 选择其他成员上传的文件 → 删除
2. ✅ 验证: 显示"权限不足"或"删除失败"提示

## 🔍 聊天记录搜索测试

### 1. 搜索功能测试

**场景1: 基本关键词搜索**
1. 进入群聊 → 点击右上角设置 → 选择"聊天记录"
2. 输入关键词"天气" → 点击"搜索"
3. ✅ 验证: 显示包含"天气"的消息
4. ✅ 验证: 关键词被高亮显示（黄色背景）
5. ✅ 验证: 显示发送者头像和昵称
6. ✅ 验证: 显示发送时间

**场景2: 不区分大小写搜索**
1. 输入关键词"HELLO" → 搜索
2. ✅ 验证: 能搜索到"hello", "Hello", "HELLO"等

**场景3: 空关键词搜索**
1. 不输入任何关键词 → 点击搜索
2. ✅ 验证: 显示提示"请输入搜索关键词"

### 2. 时间筛选测试

**场景1: 设置开始时间**
1. 在搜索页面 → 点击"开始时间" → 选择昨天的日期 → 搜索
2. ✅ 验证: 只显示昨天及之后的消息

**场景2: 设置时间范围**
1. 设置开始时间为3天前 → 设置结束时间为昨天 → 搜索
2. ✅ 验证: 只显示3天前到昨天之间的消息

**场景3: 重置筛选**
1. 设置了时间范围后 → 点击"重置"按钮
2. ✅ 验证: 开始时间和结束时间被清空

### 3. 消息跳转和定位测试

**场景1: 点击搜索结果跳转**
1. 搜索关键词 → 点击任意一条搜索结果
2. ✅ 验证: 跳转到聊天页面
3. ✅ 验证: 自动滚动到该消息
4. ✅ 验证: 消息高亮显示（黄色背景）
5. ✅ 验证: 3秒后高亮自动消失

**场景2: 消息不存在**
1. 手动构造URL，传入不存在的messageId
2. ✅ 验证: 显示"消息不在当前页面"提示
