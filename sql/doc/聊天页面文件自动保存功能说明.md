# 聊天页面文件自动保存到群文件功能说明

> **日期**: 2026-02-23  
> **版本**: v1.0  
> **功能**: 群聊时上传的文件自动保存到群文件列表

---

## 📋 功能概述

在群聊中，用户通过聊天页面上传的图片、视频、文件会自动保存到群文件列表中，方便后续查看和管理。

### 核心特性

1. ✅ **自动保存**：群聊时上传文件自动保存到群文件
2. ✅ **不影响单聊**：单聊时不会保存到群文件
3. ✅ **支持多种类型**：图片、视频、文件都会自动保存
4. ✅ **静默保存**：保存失败不影响消息发送
5. ✅ **无需额外操作**：用户无感知，自动完成

---

## 🎯 实现原理

### 工作流程

```
用户在群聊中上传文件
    ↓
1. 上传文件到文件服务（获取 URL）
    ↓
2. 发送文件消息到聊天
    ↓
3. 判断是否为群聊
    ↓ (是群聊)
4. 调用群文件上传接口
    ↓
5. 保存到群文件列表
    ↓
完成（用户可在群文件中查看）
```

## 🔑 关键设计点

### 1. 条件判断

```typescript
if (chatType.value === 'group') {
    // 只在群聊时保存到群文件
}
```

- 通过 `chatType` 判断是否为群聊
- 单聊时不会触发群文件保存

### 2. 异步处理

```typescript
uploadGroupFile(targetId.value, result.tempFilePath).then((res) => {
    console.log('[Chat] 文件已保存到群文件:', res)
}).catch((err) => {
    console.error('[Chat] 保存到群文件失败:', err)
    // 不影响消息发送
})
```

- 使用 Promise 异步处理
- 保存失败不影响消息发送
- 只在控制台输出日志，不打断用户操作

### 3. 文件路径传递

```typescript
uploadGroupFile(targetId.value, result.tempFilePath)
```

- 使用 `result.tempFilePath` 传递文件路径
- 后端会重新上传文件到文件服务
- 确保文件正确保存到 `im/group/{groupId}/` 目录

## 📊 用户体验

### 发送文件流程

1. 用户在群聊中点击 "+" 按钮
2. 选择"相册"、"文件"或"视频"
3. 选择要发送的文件
4. 文件上传并发送到聊天
5. **自动保存到群文件**（用户无感知）
6. 用户可以在"群设置 → 群文件"中查看

### 查看群文件

1. 进入群聊
2. 点击右上角设置按钮
3. 选择"群文件"
4. 查看所有群成员上传的文件
5. 可以按类型筛选（图片/视频/文件）
6. 可以下载、预览、删除文件

---

## ⚠️ 注意事项

### 1. 权限控制

- 只有群成员可以上传文件
- 上传者和群主可以删除文件
- 所有群成员可以查看和下载文件

### 2. 文件存储

- 文件存储在 `im/group/{groupId}/` 目录
- 文件信息保存在 `infra_file` 表
- 群文件关联保存在 `im_group_file` 表

### 3. 错误处理

- 保存到群文件失败不影响消息发送
- 只在控制台输出错误日志
- 用户可以正常发送和查看消息

### 4. 性能考虑

- 异步保存，不阻塞消息发送
- 不影响聊天体验
- 文件上传只进行一次（复用已上传的文件）
