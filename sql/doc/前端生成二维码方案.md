# 前端生成二维码方案（备选）

## 方案说明

如果你想在前端直接生成二维码，可以尝试以下方案。但需要注意 uniappx 的兼容性。

## 方案 1：使用 qrcode.js（推荐尝试）

### 1. 安装依赖

```bash
npm install qrcode
```

### 2. 修改 group-qrcode.uvue

```typescript
// 导入库（需要验证 uniappx 是否支持）
import QRCode from 'qrcode'

/**
 * 生成二维码
 */
async function generateQRCode() {
  if (!inviteCode.value || !qrCodeUrl.value) {
    console.log('[GroupQRCode] 数据不完整，无法生成二维码')
    return
  }

  try {
    // 使用 qrCodeUrl 生成二维码
    const dataUrl = await QRCode.toDataURL(qrCodeUrl.value, {
      width: 300,
      margin: 2,
      color: {
        dark: '#000000',
        light: '#FFFFFF'
      }
    })
    
    // 直接使用 data URL
    qrCodeImageUrl.value = dataUrl
    
    console.log('[GroupQRCode] 二维码生成成功')
  } catch (e) {
    console.error('[GroupQRCode] 生成二维码失败:', e)
    
    // 如果前端生成失败，降级到后端生成
    await generateQRCodeFromBackend()
  }
}

/**
 * 降级方案：使用后端生成
 */
async function generateQRCodeFromBackend() {
  const remoteUrl = `${BASE_URL}/app-api/system/im/group/invite/qrcode-image?code=${inviteCode.value}&groupId=${groupId.value}`
  
  const downloadRes = await uni.downloadFile({ url: remoteUrl })
  
  if (downloadRes.statusCode === 200) {
    qrCodeImageUrl.value = downloadRes.tempFilePath
  }
}
```

### 3. 修改模板

```vue
<template>
  <!-- 二维码 -->
  <view class="qrcode-container">
    <image 
      v-if="qrCodeImageUrl" 
      :src="qrCodeImageUrl" 
      class="qrcode-image"
      mode="aspectFit"
    ></image>
  </view>
</template>
```

## 方案 2：使用 Canvas 手动实现

### 优点
- 不依赖第三方库
- 完全可控

### 缺点
- 实现复杂
- 需要实现 QR Code 算法
- 维护成本高

### 参考实现

  // 2. 生成 QR Code 矩阵（需要实现 QR Code 算法）
  const matrix = generateQRMatrix(qrCodeUrl.value)
  
  // 3. 绘制到 Canvas
  const moduleSize = size / matrix.length
  
  for (let row = 0; row < matrix.length; row++) {
    for (let col = 0; col < matrix[row].length; col++) {
      if (matrix[row][col]) {
        ctx.fillStyle = '#000000'
        ctx.fillRect(
          col * moduleSize,
          row * moduleSize,
          moduleSize,
          moduleSize
        )
      }
    }
  }
  
  // 4. 导出为图片
  ctx.draw(false, () => {
    uni.canvasToTempFilePath({
      canvasId: canvasId,
      success: (res) => {
        qrCodeImageUrl.value = res.tempFilePath
      }
    })
  })

## 方案对比

| 方案 | 优点 | 缺点 | 推荐度 |
|------|------|------|--------|
| 后端生成（当前） | ✅ 稳定可靠<br>✅ 质量保证<br>✅ 跨平台一致 | ❌ 需要网络请求 | ⭐⭐⭐⭐⭐ |

## 测试步骤

如果你想尝试前端生成方案：

### 1. 安装依赖
```bash
cd shengyu-ui/shengyu-ui-admin-uniappx
npm install qrcode
```

### 2. 修改代码
按照上面的方案 1 修改 `group-qrcode.uvue`

### 3. 测试兼容性
- ✅ H5 平台（浏览器）
- ❓ Android 平台
- ❓ iOS 平台

### 4. 验证功能
- 二维码是否正常显示
- 扫描是否能识别
- 保存到相册是否正常
- 分享功能是否正常

## 建议

### 开发阶段
可以尝试前端生成方案，验证兼容性

### 生产环境
建议使用后端生成方案，原因：
1. **稳定性**：后端方案已验证可用
2. **质量**：ZXing 生成的二维码质量更好
3. **扩展性**：后端可以添加 logo、颜色等自定义功能
4. **统一性**：所有平台表现一致

## 混合方案（最佳实践）

```typescript
/**
 * 智能选择生成方案
 */
async function generateQRCode() {
  // 优先尝试前端生成（快速）
  try {
    await generateQRCodeLocally()
  } catch (e) {
    console.log('前端生成失败，降级到后端生成')
    // 降级到后端生成（可靠）
    await generateQRCodeFromBackend()
  }
}
```

这样可以兼顾速度和可靠性。
