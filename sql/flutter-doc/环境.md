## 📱 五、安装 Android 模拟器

### 5.1 安装模拟器组件
进入 SDK 工具目录：
```bash
cd ~/app/cmdline-tools/latest/bin
```

执行安装命令：
```bash
# 安装模拟器程序
./sdkmanager "emulator"

# 安装 Intel Mac 专用系统镜像（x86_64 架构 + Google Play）
./sdkmanager "system-images;android-36;google_apis_playstore;x86_64"
```

**重要提示**：
- Intel Mac **必须**使用 `x86_64` 架构镜像
- **不要**下载 `arm64-v8a` 镜像（仅适用于 Apple Silicon M 系列芯片）
- 选择 `google_apis_playstore` 版本，包含完整 Google 服务

### 5.2 验证安装
```bash
./sdkmanager --list_installed | grep -E "emulator|system-images;android-36"
```

预期输出：
```
emulator                                                                        | 36.5.11           | Android Emulator
system-images;android-36;google_apis_playstore;x86_64                           | 7                 | Google Play Intel x86_64 Atom System Image
```

## 🖥️ 六、创建虚拟设备（AVD）

### 6.1 查看可用设备预设
```bash
./avdmanager list device
```

常用设备列表：
```
id: 6 or "pixel_6"
    Name: Pixel 6
    OEM: Google

id: 7 or "pixel_7"
    Name: Pixel 7
    OEM: Google

id: 1 or "Nexus 5X"
    Name: Nexus 5X
    OEM: Google
```

### 6.2 创建模拟器实例
```bash
./avdmanager create avd \
  -n "pixel_36_x86" \
  -k "system-images;android-36;google_apis_playstore;x86_64" \
  -d "pixel_6" \
  --force
```

**参数说明**：
| 参数 | 值 | 说明 |
|------|-----|------|
| `-n` | pixel_36_x86 | 模拟器名称（自定义） |
| `-k` | system-images;... | 系统镜像包名 |
| `-d` | pixel_6 | 设备预设型号 |
| `--force` | - | 覆盖同名配置 |

### 6.3 查看已创建的 AVD
```bash
./avdmanager list avd
```

预期输出：
```
Available Android Virtual Devices:
    Name: pixel_36_x86
    Path: /Users/zsy/.android/avd/pixel_36_x86.avd
```

## 🚀 七、启动模拟器

### 7.1 基础启动命令
```bash
./emulator -avd pixel_36_x86
```

### 7.2 推荐启动命令（Intel Mac 优化版）
```bash
./emulator -avd pixel_36_x86 \
  -gpu host \
  -memory 4096 \
  -cores 4 \
  -no-boot-anim \
  -partition-size 4096
```

**参数详解**：
| 参数 | 作用 | 推荐值 |
|------|------|--------|
| `-gpu host` | 调用 macOS 原生 GPU 加速 | 必选 |
| `-memory` | 分配内存 | 4096 (4GB) |
| `-cores` | 分配 CPU 核心数 | 4 |
| `-no-boot-anim` | 跳过开机动画，加速启动 | 推荐 |
| `-partition-size` | 虚拟磁盘大小 (MB) | 4096 (4GB) |

### 7.3 后台启动模拟器
```bash
# 后台启动并忽略输出
nohup ./emulator -avd pixel_36_x86 -gpu host -memory 4096 -no-boot-anim > /dev/null 2>&1 &

# 或使用 screen 会话
screen -S emulator
./emulator -avd pixel_36_x86 -gpu host -memory 4096
# 按 Ctrl+A+D 退出 screen 会话（模拟器继续运行）
```

### 7.4 验证模拟器启动
```bash
# 查看已连接设备
adb devices

# 预期输出：
# List of devices attached
# emulator-5554    device
```

## 🔍 九、常用调试命令

### 9.1 ADB 常用命令
```bash
# 查看设备
adb devices

# 查看日志（过滤 Flutter）
adb logcat | grep -i flutter

# 查看完整日志
adb logcat -v time

# 清除日志
adb logcat -c

# 安装 APK
adb install -r app-release.apk

# 卸载应用
adb uninstall com.example.yourapp

# 重启 adb 服务
adb kill-server
adb start-server

# 截屏
adb shell screencap -p /sdcard/screen.png
adb pull /sdcard/screen.png ~/Desktop/

# 录制屏幕（最多 180 秒）
adb shell screenrecord --time-limit 180 /sdcard/demo.mp4
adb pull /sdcard/demo.mp4 ~/Desktop/
```

### 9.2 模拟器管理命令

# 查看所有 AVD

# 删除 AVD

./emulator -list-avds

# 冷启动（不使用快照）
./emulator -avd pixel_36_x86 -no-snapshot-load

# 重置模拟器数据
./emulator -avd pixel_36_x86 -wipe-data

## ⚠️ 十、常见问题排查

### 10.1 Flutter 找不到 Android SDK
**问题**：
```
✗ Unable to locate Android SDK.
```

**解决**：
```bash
flutter config --android-sdk $HOME/app
flutter doctor
```

### 10.2 许可证未接受
**问题**：
```
Licenses not accepted
```

**解决**：
```bash
./sdkmanager --licenses
# 或
flutter doctor --android-licenses
```

### 10.3 模拟器启动黑屏/卡顿
**问题**：模拟器启动后黑屏或极度卡顿

**解决**：
```bash
# 使用软件渲染
./emulator -avd pixel_36_x86 -gpu swiftshader_indirect

# 或禁用硬件加速
./emulator -avd pixel_36_x86 -gpu off
```

### 10.4 模拟器启动失败（HAXM 错误）
**问题**：提示 HAXM not installed

**说明**：Intel Mac 使用 HVF (Hypervisor.framework)，无需 HAXM，可忽略此提示

**验证虚拟化支持**：
```bash
sysctl kern.hv_support
# 应输出：kern.hv_support: 1
```

### 10.5 磁盘空间不足
**问题**：
```
No space left on device
```

**解决**：
```bash
# 1. 清理旧模拟器
./avdmanager delete avd -n <旧名称>

# 2. 扩大分区重新创建
./emulator -avd pixel_36_x86 -partition-size 8192

# 3. 清理 SDK 缓存
rm -rf $HOME/.android/cache
```

### 10.6 Flutter 识别不到模拟器
**问题**：`flutter devices` 不显示模拟器

**解决**：
```bash
# 1. 确保 platform-tools 在 PATH 中
echo $PATH | grep platform-tools

# 2. 重启 adb
adb kill-server
adb start-server

# 3. 重新检查
flutter doctor -v
```

### 10.7 Java 版本不兼容
**问题**：编译报错或 SDK 工具无法运行

**解决**：
```bash
# 安装 JDK 11（推荐）
brew install openjdk@11

# 配置 JAVA_HOME
export JAVA_HOME=$(/usr/libexec/java_home -v 11)

# 验证
java -version
# 应输出：openjdk version "11.x.x"
```

## 📝 十二、快速参考卡片

### 启动开发环境（每日工作流）
```bash
# 1. 启动模拟器（终端 1）
cd ~/app/cmdline-tools/latest/bin
./emulator -avd pixel_36_x86 -gpu host -memory 4096 -no-boot-anim &

# 2. 等待模拟器启动（约 30-60 秒）
adb wait-for-device
sleep 10

# 3. 运行 Flutter 项目（终端 2）
cd ~/your_flutter_project
flutter run
```

### 一键启动脚本（可选）
创建 `~/bin/start-dev.sh`：
```bash
#!/bin/bash
echo "🚀 Starting Android Emulator..."
cd ~/app/cmdline-tools/latest/bin
./emulator -avd pixel_36_x86 -gpu host -memory 4096 -no-boot-anim &

echo "⏳ Waiting for emulator to boot..."
adb wait-for-device
sleep 15

echo "✅ Emulator ready!"
echo "📱 Run: flutter run"
```

赋予执行权限：
```bash
chmod +x ~/bin/start-dev.sh
```

使用：
```bash
~/bin/start-dev.sh
```
