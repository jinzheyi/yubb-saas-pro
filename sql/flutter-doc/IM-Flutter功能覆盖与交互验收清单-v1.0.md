# IM Flutter 功能覆盖与交互验收清单 v1.0

> 文档日期：2026-04-29  
> 文档定位：防止 IM 高频功能漏实现的覆盖清单与交互验收清单  

---

## 1. 目标

这份文档用于冻结一个原则：

提供给 Flutter 的参考资料不仅是“接口线索”，更是“功能覆盖与交互行为参考”。

因此，以下高频能力默认都属于 Flutter 版本必须考虑的范围，不能因为没有单独写旧页面逻辑就漏掉。

---

## 2. 会话列表页必须覆盖

### 2.1 基础能力

- 会话列表展示
- pinned / normal 分区
- 未读角标
- `@我` 标识
- 分类筛选
- 搜索入口
- 下拉刷新

### 2.2 菜单交互

- Mobile：长按菜单
- Web/Desktop：右键菜单

菜单动作至少包含：

- 置顶 / 取消置顶
- 标记已读 / 未读
- 免打扰开关
- 删除会话

---

## 3. 聊天页必须覆盖

### 3.1 输入与发送

- 文本发送
- 图片发送
- 视频发送
- 文件发送
- 语音发送
- 位置发送
- 名片发送
- emoji 发送
- 自定义表情发送
- 引用回复
- 合并转发

### 3.2 输入区形态

- 文本输入模式
- 语音输入模式
- `+` 号更多面板
- emoji 面板
- 引用编辑态

### 3.3 时间线交互

- 历史翻页
- 引用定位
- 高亮锚点
- 断线补拉后合并

### 3.4 消息菜单

- Mobile：长按消息菜单
- Web/Desktop：右键消息菜单

消息菜单至少包含：

- 复制
- 引用
- 转发
- 收藏
- 删除
- 撤回

按消息类型可附加：

- 保存图片
- 播放 / 暂停语音
- 打开文件
- 定位位置

### 3.5 语音消息交互

- 播放
- 暂停
- 续播
- 播放完成
- 未听转已听
- 前后台状态恢复

### 3.6 媒体交互

- 图片预览
- 视频播放
- 文件打开
- 文件下载

---

## 4. emoji 与自定义表情必须覆盖

### 4.1 emoji

- emoji 选择面板
- emoji 插入文本输入框
- 消息中 emoji 渲染

### 4.2 自定义表情

- 自定义表情发送
- 自定义表情收藏 / 管理入口
- 表情文件上传
- 贴纸 / 表情消息渲染

---

## 5. `+` 号面板必须覆盖

默认能力清单：

- 相册
- 拍照
- 视频
- 文件
- 位置
- 名片
- 音视频通话入口

规则：

1. UI 可以调整排序
2. 但能力项不能无故缺失
3. 所有入口统一走 `MorePanelActionCoordinator`

- 部门成员浏览

- 发起单聊
- 创建群聊

## 9. 收藏功能必须覆盖

- 收藏消息

- 收藏详情
- 收藏再转发

## 10. 文件与群文件能力必须覆盖

- 聊天文件上传
- 文件消息发送
- 文件预览
- 文件下载
- 聊天媒体页
- 群文件列表

注意：

群文件索引可以复用现有 `fileId`，但“群文件能力”本身不能漏掉。

## 11. 多端交互映射

### 11.1 Mobile

- 长按代替右键
- 底部 action sheet / bottom sheet
- 全屏媒体预览

### 11.2 Web / Desktop

- 右键菜单
- 更丰富的 hover
- 拖拽上传
- 多栏布局

规则：

交互入口可以变，但业务动作集合不能缩水。

## 12. 当前文档映射结论

以下专题已经承接了大部分功能：

- 会话列表：`IM-Flutter会话列表详细设计-v1.0.md`
- 聊天页：`IM-Flutter聊天页详细设计-v1.0.md`
- 群设置/通讯录/搜索：`IM-Flutter群设置通讯录搜索详细设计-v1.0.md`
- 上传：`IM-Flutter文件上传与发送链路设计-v1.0.md`
- 文件预览：文件预览专题全套

但为了避免遗漏，本清单仍作为总验收基线。

## 13. 验收标准

1. 会话列表右键/长按菜单不能漏
2. 聊天页消息菜单不能漏
3. 语音消息暂停续播不能漏
4. emoji / 自定义表情不能漏
5. `+` 号面板能力不能漏
6. 群设置 / 单聊设置关键动作不能漏
7. 群文件能力不能漏
