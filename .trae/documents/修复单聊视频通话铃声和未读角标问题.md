# 修复单聊视频通话铃声和未读角标问题

## Context

用户报告了两个单聊视频通话的问题：
1. **视频通话没有铃声** — 去电界面应播放 `call_ringtone.mp3`，但实际听不到铃声
2. **发送的通话记录给自己产生未读角标** — 重新登录后，自己发出的通话记录在会话列表显示未读数字

## 问题1：视频通话没有铃声

### 根因分析

`OutgoingCallPage.initState()` 的执行顺序：
1. `Future.microtask` → `controller.initialize()` → `controller.startOutgoing()` → `_callMediaController.prepare()` → `_configureAudioSession()`（重新配置 AudioSession）
2. `_startRingtone()`（播放铃声）

`_configureAudioSession()` 调用 `AudioSession.instance.configure()` 会重新配置音频会话，**中断正在播放的音频**（just_audio 的 AudioPlayer）。

虽然 `_startRingtone()` 和 `prepare()` 几乎同时启动，但 `prepare()` 中的 `_configureAudioSession()` 会抢占音频焦点，导致铃声被中断。

### 修复方案

**文件**: `outgoing_call_page.dart`

将 `_startRingtone()` 的调用提前到 `initState` 的最开始（在 `Future.microtask` 之前），确保铃声在 `_configureAudioSession()` 被调用之前就已经开始播放。

同时，在 `CallController._onRemoteStreamChanged()`（通话连接成功时）添加回调通知页面停止铃声，确保接听后铃声停止。

具体改动：
1. `OutgoingCallPage.initState()` 中，将 `_startRingtone()` 移到 `Future.microtask()` 之前
2. 在 `ref.listen<CallState>` 中监听 `pageStatus == CallPageStatus.connected`，此时调用 `_stopRingtone()`

## 问题2：发送的通话记录给自己产生未读角标

### 根因分析

后端 `broadcastCallRecordMessage()` 方法遍历 `chatUsers`（会话所有参与者），**包括发送者自己**。发送者通过 WebSocket 收到自己的通话记录消息后：
1. 触发 `messageReceived` 事件 → 本地 DB 写入消息
2. 触发 `conversationHint` 事件 → 触发 `syncIncrementally()` 从服务端拉取会话列表
3. 重新登录时，服务端返回的 `im_conversation_user_state` 中该会话的 `unread_count` 可能非零

虽然 `upsertAfterMessageForSender` 设置了 `unread_count = 0`，但发送者收到自己的广播消息后，前端的 `conversationHint` 处理逻辑中 `_shouldSkipSyncForLocalUpdate` 检查不到本地更新记录（因为广播消息不是本地发送触发的），导致执行了不必要的 sync。

### 修复方案

**文件**: `ImCallServiceImpl.java` — `broadcastCallRecordMessage()` 方法

在广播循环中跳过发送者，不给自己发送通话记录消息的 WebSocket 广播：

```java
for (ImChatUserDO chatUser : chatUsers) {
    // 跳过发送者，不给自己广播通话记录消息
    if (chatUser.getUserId().equals(message.getSenderId())) {
        continue;
    }
    // ... 原有广播逻辑
}
```

这样发送者不会通过 WebSocket 收到自己的通话记录消息，避免了不必要的 `conversationHint` → `syncIncrementally()` 链路。

## 修改文件清单

| 文件 | 改动 |
|------|------|
| `outgoing_call_page.dart` | 调整 `_startRingtone()` 调用时机 + 连接成功时停止铃声 |
| `ImCallServiceImpl.java` | `broadcastCallRecordMessage()` 中跳过发送者 |

## 验证

1. 发起单聊视频通话，确认能听到铃声
2. 通话结束后，检查会话列表，确认发送者没有未读角标
3. 重新登录后，检查会话列表，确认发送者没有未读角标
4. 确认接收方仍能正常收到通话记录消息和未读角标
