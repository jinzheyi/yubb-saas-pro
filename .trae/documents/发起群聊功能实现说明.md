# 发起群聊功能实现说明

## 功能概述

在消息列表页面右上角添加发起群聊入口，点击后跳转到通讯录选择页面，用户可以选择联系人创建群聊。

## 一、功能入口

### 1.1 消息列表页面 (`pages/message/message.uvue`)

**位置**: 右上角第二个图标（扫一扫右侧）

**图标**: `&#xea74;` (对话图标)

**点击事件**: `handleInitiateGroup()`

```typescript
/**
 * 发起群聊
 */
function handleInitiateGroup() {
    uni.navigateTo({
        url: '/pages/contacts/initiate-group'
    })
}
```

### 1.2 右上角图标说明

| 图标 | Unicode | 功能 | 状态 |
|------|---------|------|------|
| 扫一扫 | `&#xea8b;` | 扫描二维码 | 开发中 |
| 发起群聊 | `&#xea74;` | 创建群聊 | ✅ 已实现 |

## 二、组件化设计

### 2.1 ContactSelector 组件

**路径**: `components/contact-selector/contact-selector.uvue`

**功能**: 可复用的联系人选择组件，支持字母索引、分组显示、多选功能

**特性**:
- ✅ 字母分组显示（A-Z）
- ✅ 右侧字母索引快速定位
- ✅ 可选的快捷分类入口（群组、关注、组织、部门）
- ✅ 支持单选/多选模式
- ✅ 自动生成假名数据（用于演示）
- ✅ 支持自定义联系人数据
- ✅ 响应式设计，适配各种屏幕

**Props**:
```typescript
{
  showCategories: Boolean,  // 是否显示快捷分类，默认 false
  selectable: Boolean,      // 是否显示复选框，默认 false
  contacts: Array          // 联系人数据数组，为空时使用默认假名数据
}
```

**Events**:
```typescript
{
  select: (item: any) => void,           // 点击联系人时触发
  'category-click': (item: any) => void  // 点击分类时触发
}
```

### 2.2 数据结构

**联系人数据结构**:
```typescript
{
  id: number,           // 联系人 ID
  name: string,         // 姓名（假名）
  role: string,         // 职位
  avatarText: string,   // 头像文字
  avatarBg: string,     // 头像背景色
  pinyin: string,       // 拼音首字母（A-Z）
  selected: boolean,    // 是否选中
  isCurrentUser: boolean  // 是否是当前登录用户
}
```

**假名数据生成**:
- **当前用户**: 第一个联系人为当前登录用户，默认选中且不能取消
- **姓氏**: 张、李、王、刘、陈、杨、赵、黄、周、吴、徐、孙、胡、朱、高、林、何、郭、马、罗（20个）
- **名字**: 伟、芳、娜、秀英、敏、静、丽、强、磊、军、洋、勇、艳、杰、娟、涛、明、超、秀兰、霞（20个）
- **职位**: 高级经理、部门经理、项目经理、开发工程师、测试工程师、产品经理、设计师、运营专员、市场专员、行政专员（10种）
- **颜色**: 10种预设颜色循环使用
- **拼音**: A-Z 循环分配

**特殊逻辑**:
- 当前登录用户始终排在第一位
- 当前用户默认选中，且不能取消选中
- 尝试取消选中当前用户时，显示提示"不能取消选择自己"
- 创建群聊至少需要选择2人（包括自己）

### 3.3 组件使用

```vue
<template>
  <view class="page">
    <!-- 头部和搜索栏 -->
    <view class="header">...</view>
    <view class="search-wrap">...</view>

    <!-- 使用联系人选择组件 -->
    <contact-selector 
      :show-categories="true"
      :selectable="true"
      :contacts="contactList"
      @select="handleSelect"
      @category-click="handleCategory"
    />

    <!-- 底部操作栏 -->
    <view class="footer">
      <text class="selected-text">已选择 {{ selectedCount }} 人</text>
      <button :disabled="selectedCount === 0" @click="handleConfirm">
        确定({{ selectedCount }}/500)
      </button>
    </view>
  </view>
</template>

<script setup lang="uts">
import ContactSelector from '../../components/contact-selector/contact-selector.uvue'

// 生成50条假名联系人数据
const contactList = ref(generateContacts())

const selectedCount = computed(() => {
  return contactList.value.filter(item => item.selected).length
})

function handleSelect(item : any) {
  // 选择逻辑已在组件内部处理
  console.log('选择联系人:', item.name, '选中状态:', item.selected)
}

function handleCategory(item : any) {
  uni.showToast({
    title: '功能开发中',
    icon: 'none'
  })
}

function handleConfirm() {
  const selectedContacts = contactList.value.filter(item => item.selected)
  console.log('已选择的联系人:', selectedContacts)
  // TODO: 调用创建群聊 API
}
</script>
```

## 四、样式设计

### 4.1 配色方案

**头部导航**:
- 背景色: `#1677FF` (主题蓝)
- 文字颜色: `#FFFFFF`

**快捷分类图标背景**:
- 群组: `#fb923c` (橙色)
- 关注: `#facc15` (黄色)
- 组织: `#84cc16` (绿色)
- 部门: `#06b6d4` (青色)

**复选框**:
- 未选中: 灰色边框 `#d1d5db`
- 已选中: 蓝色背景 `#1677FF`

### 4.2 布局特点

1. **头部固定**: 蓝色导航栏 + 搜索栏
2. **内容滚动**: 分类 + 联系人列表可滚动（使用组件）
3. **底部固定**: 操作栏固定在底部，适配安全区域
4. **右侧索引**: 字母索引固定在右侧，快速定位

### 4.3 交互反馈

- 点击联系人: 切换选中状态，复选框动画
- 点击分类: 显示"功能开发中"提示
- 点击确定: 显示"创建群聊中..."加载提示
- 点击字母索引: 滚动到对应分组

## 十一、技术亮点

### 11.1 组件化设计
- 将联系人选择功能抽取为独立组件
- 支持多种使用场景（发起群聊、转发消息、通讯录等）
- Props 和 Events 设计灵活，易于扩展

### 11.2 数据生成
- 使用真实的中文姓名组合生成假名
- 自动分配拼音首字母用于分组
- 颜色、职位等属性循环使用，保证数据多样性

### 11.3 性能优化
- 使用 computed 计算属性自动分组
- 字母索引快速定位，减少滚动操作
- 响应式数据更新，避免不必要的重渲染

### 11.4 用户体验
- 右侧字母索引，快速定位联系人
- 选中状态实时反馈
- 底部操作栏固定，方便操作
- 适配安全区域，兼容各种设备
