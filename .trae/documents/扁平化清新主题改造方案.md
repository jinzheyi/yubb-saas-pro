# 双端扁平化清新主题改造方案

## Context（背景）

当前两端（admin-vue3 + platform-vue3）已完成 Semi 主题桥接与 AntD 视觉对齐，但整体风格仍偏深色厚重：
- 侧边栏深色 `#001529`，与参考图"浅色与主背景融合"风格不符
- 主色 `#0064FA`（Semi 蓝），与参考图品牌深蓝 `#2563EB` 不符
- 圆角偏大（8px）、阴影偏重，与参考图"扁平、几乎无投影"不符
- 字体未建立四层灰阶层级

用户希望两端主题风格**无限趋近参考图（AI 生成扁平化清新自然风格）**，要求双端同步、系统性调整。

## 核心策略

**保留 Semi 主题**（不注释 main.ts），通过覆盖 Semi 蓝色 RGB 分量让整个色板跟随 `#2563EB`，复用既有 body.semi 桥接层。优势：
1. 不破坏已完成的桥接工作（index.scss body.semi 块继续生效）
2. 改动最小、最可控、可逆
3. setPrimaryLight() 会自动为新主色生成 light-3/5/7/9 + dark-2 衍生色

参考图视觉令牌：
- 主色 `#2563EB`；背景 `#F5F7FA`；卡片 `#FFFFFF`；边框 `#E5E7EB`
- 成功 `#22C55E`；警告 `#F59E0B`；危险 `#EF4444`
- 圆角 2/4/6px；几乎无阴影
- 字体四层：标题 `#1F2937` / 正文 `#4B5563` / 次要 `#9CA3AF` / 禁用 `#D1D5DB`

## 阶段 2：Semi 主色覆盖 + Store 默认主题

### 2.1 index.scss body.semi 块覆盖 Semi 蓝色 RGB 分量

文件：`shengyu-ui-{admin,platform}-vue3/src/styles/index.scss`（在 body.semi 块 L52 附近主色注释下追加）

Semi 主色基于 `--semi-blue-0/1/2/5/6/7` RGB 分量（见 node_modules/advance-semi-theme/dist/core/variables.css L10-17, L87-93）。覆盖这 6 个 RGB 让整个 Semi 色板跟随 `#2563EB`：

```scss
body.semi {
  /* ---- Semi 主色 RGB 分量覆盖（让 Semi 色板跟随 #2563EB）----
   * 原值: blue-5=0,100,250 (#0064FA) | 新值: 37,99,235 (#2563EB)
   * 衍生色参考 Tailwind blue 色板生成 */
  --semi-blue-0: 239, 246, 255 !important;  /* #EFF6FF light-default 背景 */
  --semi-blue-1: 219, 234, 254 !important;  /* #DBEAFE light-hover */
  --semi-blue-2: 191, 219, 254 !important;  /* #BFDBFE light-active */
  --semi-blue-5: 37, 99, 235 !important;    /* #2563EB primary */
  --semi-blue-6: 29, 78, 216 !important;    /* #1D4ED8 primary-hover */
  --semi-blue-7: 30, 64, 175 !important;    /* #1E40AF primary-active */

  /* 同步覆盖 Element Plus 衍生色 RGB（setPrimaryLight 写入 <html> 后兜底）*/
  --el-color-primary-rgb: 37, 99, 235 !important;
}
```

既有 L107-112 的 `--el-color-primary-rgb` 等硬编码 RGB 也需同步改为新主色。

### 2.4 主题缓存版本兜底

`wsCache.get(CACHE_KEY.THEME)` 会读取老用户 localStorage 旧主题，新默认值不生效。在 app.ts state 顶部追加版本判断：
```ts
const THEME_VERSION = 'v2-flat-20260919'
const cachedThemeVer = wsCache.get('theme_version')
if (cachedThemeVer !== THEME_VERSION) {
  wsCache.delete(CACHE_KEY.THEME)
  wsCache.set('theme_version', THEME_VERSION)
}
```
（仅当版本不一致时清空旧主题缓存，触发回退默认值）

## 潜在风险

1. **localStorage 旧主题缓存**：阶段 2.4 已通过版本号兜底清空。
2. **`<html>` inline style 残留**：`setPrimaryLight` 已写入旧 light-* 值在用户首次刷新前可能短暂残留，通过版本号触发缓存清空，再触发 `setPrimaryLight()` 重算。
3. **登录页 SVG 对比度**：`login-box-bg.svg` / `login-bg.svg` 在浅色背景下可能对比度不足，视觉验证后按需替换浅色版本。
4. **业务页面散落硬编码**：调研确认仅 5 个核心文件含主题色硬编码，业务页面无散落硬编码；但需双端全局目测 dialog/drawer/button 颜色。
5. **Semi 主题可逆性**：保留 main.ts 注释代码不删除（本方案不动 main.ts），便于回退。
